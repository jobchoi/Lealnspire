# Lealnspire 교사·보호자 안내

> 아이와 함께 Lealnspire를 쓰는 선생님과 보호자를 위한 한 장짜리 안내입니다. 실제 화면 동작을 기준으로 썼습니다(2026-11-21, T26).

## 무엇을 배우나요

> 2026-11-25 갱신: 2단원(조건 `if`/`else`), 3단원(조건 반복 `while`), 4단원(함수), 5단원(변수), 6단원(논리 not/and/or), 7단원(매개변수), 8단원(반환값), 9단원(이벤트), 10단원(리스트), 11단원(탐색), 12단원(종합·전체 완주), 영어가 추가됐습니다(2026-11-27 6~12단원).

로봇에게 블록으로 명령을 내려 별까지 데려가는 퍼즐입니다. 1단원에서 배우는 것은 세 가지입니다.

1. **순서**: 컴퓨터는 명령을 하나씩, 놓인 순서대로 실행합니다. 순서가 바뀌면 결과도 바뀝니다.
2. **반복**: 같은 동작이 되풀이되는 패턴을 찾아 "N번 반복" 블록으로 줄여 씁니다.
3. **고치기(디버깅)**: 틀린 프로그램을 실행해 보고, 어디서 틀렸는지 찾아 고칩니다.

글을 읽지 못해도 쓸 수 있도록 블록과 버튼은 기호로 되어 있습니다(↑ 앞으로, ↶ 왼쪽으로 돌기, ↷ 오른쪽으로 돌기, ↻ 반복).

## 구성

| 구분 | 내용 |
|---|---|
| 정규 스테이지 1~8 | 1~3 크레용 스케치북(순서), 4~6 기차 마을(디버깅·반복 도입), 7~8 나의 게임기(종합). **8개를 성공하면 1단원 완료**입니다 |
| 보너스 2개 | 8번을 끝낸 뒤 열리는 선택 활동. 배운 반복을 처음 보는 맵에 써 봅니다 |
| 예측 도전 | 깬 스테이지(2·5·7, 보너스 1·2)에서 고를 수 있는 선택 활동. 실행하기 전에 로봇이 어디서 멈출지 고릅니다 |
| 2단원: 조건 (if/else) | 1단원 정규 8개를 끝내면 열림. 로봇이 "앞이 막혔는지" 보고 다음 행동을 고르는 `if`와, 아닐 때 할 일을 정하는 `else`를 배웁니다(두 가지 중 하나만 실행). **같은 코드로 여러 맵(2~3개)을 모두 지나가야 성공**이라, 길을 외우는 대신 조건을 써야 합니다 |
| 3단원: 조건 반복 (while) | 2단원을 끝내면 열림. "앞이 열려 있는 동안" 계속하는 `while`을 배웁니다. 길이가 다른 길을 같은 코드로 지나가고, 끝나지 않는 반복을 찾아 고칩니다(이 단원에서는 `if` 블록이 없습니다) |
| 4단원: 함수 (function) | 3단원을 끝내면 열림. 되풀이되는 모양을 한 번 만들어 두고(별·달 그림 카드) 여러 번 부르는 함수를 배웁니다. 만들기만 하면 실행되지 않고, 불러야 실행된다는 것도 퍼즐로 확인합니다 |
| 5단원: 변수 (variable) | 4단원을 끝내면 열림. 숫자를 담는 상자 A를 배웁니다. 맵마다 상자에 든 수가 달라 그 수를 반복 횟수로 쓰고(`repeat A`), 값을 1씩 바꾸고(`A + 1`), 값을 넣는 순서가 왜 중요한지 고쳐 봅니다 |
| 6단원: 논리 (not/and/or) | 5단원을 끝내면 열림. 로봇이 앞·왼쪽·오른쪽이 막혔는지 보고, 조건을 뒤집거나(`not`) 두 조건을 묶습니다(`and`: 둘 다, `or`: 하나라도). 한쪽만 열린 막다른 길과 양쪽이 다 열린 갈림길을 구별하고, and와 or를 바꿔 고쳐 봅니다 |
| 7단원: 매개변수 (parameter) | 6단원을 끝내면 열림. 함수가 값을 받게 하고(◆), 부를 때마다 다른 값을 건넵니다(`★(2)`, `★(A)`). 건넨 값은 그 호출에서만 쓰이고 바깥 상자 A는 바뀌지 않는다는 것을, 함수 안의 A를 ◆로 고치며 확인합니다 |
| 8단원: 반환값 (return) | 7단원을 끝내면 열림. 함수가 앞에 몇 칸이 있는지 세어 `return`으로 돌려주고, 그 값만큼 반복합니다. 건넨 값(◆)과 돌려받은 값(↩)이 다르다는 것, `return` 뒤의 블록은 실행되지 않는다는 것을 고치며 확인합니다 |
| 9단원: 이벤트 (event) | 8단원을 끝내면 열림. `on` 처리기는 놓인 순서가 아니라 신호가 와야, 온 순서대로 하나씩 실행된다는 것을 배웁니다. 닫힌 문을 신호가 열면 출발하고, 서로 바뀐 신호 연결을 고쳐 봅니다 |
| 10단원: 리스트 (list) | 9단원을 끝내면 열림. 맵마다 주어진 리스트의 값을 앞에서부터 하나씩 꺼내 쓰고(`for each`), 칸 번호가 0부터라는 것과 길이(칸 수)가 마지막 번호와 다르다는 것을 고치며 확인합니다 |
| 11단원: 탐색 (search) | 10단원을 끝내면 열림. 리스트에서 목표 값과 같은 칸을 찾고, 찾자마자 멈추면 비교가 줄어든다는 것, 앞에서부터와 뒤에서부터 중 어느 쪽이 빠른지는 입력에 따라 다르다는 것을 비교 횟수로 확인합니다 |
| 12단원: 종합 — 배운 도구를 골라요 | 11단원을 끝내면 열림. 개념 이름을 알려 주지 않고, 두 맵에서 무엇이 달라지는지 보고 필요한 도구(반복·조건, 함수·매개변수, 리스트)를 골라 씁니다. 정규 퍼즐 45개를 모두 끝내면 전체 과정 완주 화면이 나옵니다 |
| 다른 월드로 다시 풀기 | 깬 스테이지는 오른쪽 위 세 버튼으로 다른 그림체에서 다시 풀 수 있습니다 |

## 도와주는 방법 — 정답을 말하지 않고

이 게임은 일부러 정답을 알려 주지 않습니다. 아이가 막히면 아래 순서로 도와주세요.

1. **먼저 실행해 보게 하세요.** 실패해도 벌점이 없습니다. 실패하면 로봇이 멈춘 칸과 문제가 생긴 블록에 "!" 표시가 나옵니다. "고치기"를 누르면 코드는 그대로 두고 그 블록이 선택됩니다.
2. **"한 단계" 버튼으로 한 칸씩 따라가 보게 하세요.** 반복 블록에는 "2/3"처럼 몇 번째 도는 중인지 나옵니다.
3. **힌트(전구)를 누르게 하세요.** 1단계는 맵에서 볼 곳을 강조하고, 2단계는 생각해 볼 질문을 보여 줍니다.
4. 그래도 막히면 이렇게 물어 보세요.
   - "로봇이 지금 어느 쪽을 보고 있어?" (돌기는 로봇 기준입니다. 화면 기준이 아닙니다)
   - "별까지 몇 칸 가야 해? 어디서 방향을 바꿔야 해?"
   - "똑같이 되풀이되는 부분이 보여? 몇 번 되풀이돼?"
   - "로봇이 멈춘 곳은 어디야? 그 직전에 어떤 블록이 실행됐어?"

블록을 대신 놓아 주기보다 아이가 직접 실행하고 고치게 하는 편이 배우는 데 도움이 됩니다.

## 별의 의미

1단원에서는 성공하면 별 1~3개를 받습니다. 별은 **"더 짧은 코드로도 풀 수 있다"는 코드 길이 피드백**이지 실력 평가가 아닙니다. 별이 적어도 다음 스테이지는 열립니다. (기준은 잠정입니다: 스테이지별 기준 블록 수 이하면 3개, 2개 이내로 넘으면 2개, 그 외 1개) 2단원부터는 코드 길이로 별을 매기지 않고, 성공하면 별 3개입니다(짧은 코드보다 개념을 쓰는 것이 목표).

## 기록과 개인정보

- 진행 기록(깬 스테이지, 스테이지별 최고 별, 마지막으로 만든 블록)은 **이 기기의 브라우저에만** 저장되고 서버로 보내지 않습니다. 회원가입이 없습니다.
- 브라우저 기록을 지우면 함께 사라집니다. 다른 기기나 다른 브라우저로 옮겨지지 않습니다.
- 홈 화면 왼쪽 위 "ⓘ 내 기록 안내"에서 내용을 보고 지울 수 있습니다(한 번 더 확인한 뒤 지움).
- **공용 기기**(학교 컴퓨터실 등): 한 브라우저를 여러 아이가 쓰면 기록이 섞입니다. 수업이 끝나면 "내 기록 안내 → 기록 지우기"로 지우거나, 아이마다 다른 브라우저 프로필을 쓰세요.
