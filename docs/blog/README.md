## 발행 전 확인 목록

- [ ] 작업 기록과 현재 상태를 대조해 날짜, 수치, 검증 범위 및 잠정 상태를 다시 확인한다.
- [ ] 확인하지 못한 환경과 학습 효과를 성공이나 입증으로 표현하지 않았는지 확인한다.
- [ ] 이메일, 개인 경로, PC·계정 이름, 접속 정보, 비밀 정보와 다른 프로젝트의 운영 정보가 없는지 확인한다.
- [ ] 스크린샷 자리표시를 실제 이미지로 교체할 경우 개인정보와 민감정보를 가리고 내용과 권한을 확인한다.
- [ ] 제목·요약·라벨과 링크를 발행할 곳에 맞게 검토하고 사용자 승인을 받는다.
