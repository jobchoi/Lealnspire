# 게임 기획 (GAME_DESIGN)

> 표시: **[확정]** 사용자가 승인한 내용 · **[제안]** 검토 대기 중인 안 · **[미결정]** 결정이 필요한 항목

## 1. 대상 사용자 [확정]

- 프로그래밍 경험이 없는 **청소년과 성인**
- 회원가입 없이 브라우저에서 바로 시작
- [제안] 한 스테이지는 1~3분 안에 끝나는 짧은 퍼즐로 구성합니다.

## 2. MVP 목표 [확정]

- 명령의 **순서**와 **반복문**의 기본을 게임으로 이해한다.
- 플레이어가 직접 블록을 조합하고 실행 결과를 확인한다.
- 5~10개의 짧은 스테이지를 완주할 수 있다.
- 회원가입 없이 브라우저에 진행 상황을 저장한다.

## 3. 핵심 게임 루프 [제안]

```
스테이지 선택 → 목표 확인(맵, 블록 제한) → 블록 조합 → 실행
→ 로봇 애니메이션(실행 중인 블록 강조) → 결과
   ├ 성공: 별 평가(블록 수 기준) → 진행 상황 저장 → 다음 스테이지
   └ 실패: 실패 이유 표시(벽 충돌 / 목적지 미도달) → 처음으로 → 수정 → 다시 실행
```

- 실패해도 벌점 없이 바로 다시 시도합니다.
- 별 3개 기준은 "최소 블록 수 이하"입니다. 반복문을 쓰면 블록 수가 줄어 반복을 쓸 동기가 생깁니다.

## 4. 실행 규칙 [제안]

- 명령 블록: 앞으로, 왼쪽으로 돌기, 오른쪽으로 돌기
- 반복 블록: N번 반복(N은 2~10), 안에 다른 블록(반복 포함)을 넣을 수 있음
- 앞으로: 앞 칸이 벽이거나 맵 밖이면 **부딪힘으로 실패**하고 멈춤
- 돌기: 제자리에서 90도 회전, 한 단계로 셈
- 도착 칸에 들어가면 **즉시 성공**하고 멈춤
- 프로그램이 끝났는데 도착하지 못했으면 실패
- 안전장치: 기본 명령은 최대 1000단계, 반복 몸체 진입은 별도로 최대 1000회까지만 실행. 다음 실행이 상한을 넘으면 단계 초과(`stepLimit`)로 멈춤. 반복 진입은 화면 프레임을 만들지 않으며, 빈 반복만 있어도 진입 상한을 넘으면 단계 초과(상한 이내에서 끝나면 미도달)
- 블록 수: 반복 블록 자체도 1개로 셈

## 5. MVP 범위

### 포함 [제안]

- 블록 4종(위 실행 규칙)
- 블록 추가, 삭제, 순서 바꾸기, 반복 횟수 바꾸기(1차는 클릭 방식)
- 실행 / 한 단계씩 실행 / 처음으로 / 속도 조절
- 실행 중인 블록 강조, 실패 이유 메시지
- 스테이지 8개(+보너스 1개 선택), 순서대로 잠금 해제, 별 평가, 스테이지별 힌트 1개
- localStorage에 진행 상황과 스테이지별 마지막 코드 저장

### 제외 [제안]

- 조건문, 변수, 함수(다음 단원 후보)
- 아이템 줍기, 적, 움직이는 장애물
- 회원가입, 서버, 순위표, 공유
- 스테이지 편집기, 다국어, 사운드, 캐릭터 꾸미기
- 드래그 앤 드롭(MVP 이후 선택 기능)
- 블로그 자동 발행

## 6. 화면 구성 [제안]

- 화면: 첫 화면(시작/이어하기), 스테이지 목록, 게임 화면, 결과 모달
- 게임 화면: 왼쪽 맵(CSS Grid), 오른쪽 블록 팔레트와 작업 공간, 아래 실행 버튼
- 모바일: 맵을 위, 편집기를 아래에 쌓음
- 로봇의 방향은 큰 화살표로 표시
