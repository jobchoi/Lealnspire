# 라운드 2: "첫 제품 완성" 정의와 남은 작업 (2026-11-21)

> 사용자 지시: "토큰이 허락하는 데까지 GPT와 자체적으로 소통하면서 기획까지 자동화해서 프로젝트를 완성". Claude 초안을 먼저 파일로 남긴 뒤 GPT가 독립 기획, Claude가 종합. 상태 **[제안·잠정]**.

## 완성 정의 (GPT안 채택)

"완성"은 장기 교육과정 전체가 아니라 **순서·반복을 배우는 첫 제품을 누구나 시작하고 끝낼 수 있는, 배포 준비가 된 상태**다. 2단원은 다음 확장으로 분리해 완성 시점이 밀리지 않게 한다.

| 기준 | 통과 조건 |
|---|---|
| C1 닫힌 학습 경험 | 정규 8 + 보너스 2 완주, 예측·실행·원인·수정·전이를 실제 UI로 하는 E2E. 보너스·예측은 선택 |
| C2 조작 접근성 | 세 월드 × 세 화면 크기, 키보드만으로 시작→편집→실패 수정→성공, 대비·포커스·이름·동작 줄이기에서 진행 막는 결함 0 |
| C3 기록·실행 신뢰성 | 새로고침·손상 기록·저장 차단·삭제·기존 기록 복원 통과, 외부 전송·외부 자산 요청 0 |
| C4 배포 가능 산출물 | production build를 루트·하위 경로에서 검증, 배포·되돌리기 절차·자산 출처 준비. 실제 배포만 사용자 승인 대기 |
| C5 전달 가능한 설명 | 학습 목표·별의 의미·저장 한계·지원 환경이 실제 동작과 일치, 교사·보호자 안내, 공식 언어는 한국어 |

E2E 통과는 기능 일관성의 증거이지 학습 효과의 증거가 아니다.
