# T84-4 지시서 — 학습자 대시보드 "내 배움" (구현 Codex, 기획 GPT, 문구·E2E·QC Claude)

브랜치 `feature/T84-learning-history`(T84-3 위). 먼저 docs/design/learning-history.md(1-1절 결정, 2절 GPT 원문 3절 학습자 화면안), src/model/historySummary.ts(`summarizeHistory`), CLAUDE.md를 읽는다. [제안·잠정].

## 구현
1. 홈과 스테이지 목록에 큰 그림 버튼 **"내 배움"**(48px 이상, 그림 + 글자). 새 페이지 `src/view/pages/LearningPage.tsx`(AppController 화면 상태에 추가).
2. 영역(위에서 아래):
   - **해낸 퍼즐 수**: "지금까지 퍼즐 {count}개를 해냈어요" (정규 45개 기준, 진행 문서가 기준)
   - **배워 본 도구**: 12단원 개념 카드(기존 단원 기호·개념어 재사용). 완료한 퍼즐이 있는 단원은 진하게, 진행 중은 "하는 중", 안 연 단원은 흐리게. 카드를 누르면 스테이지 목록의 그 단원으로.
   - **최근 해낸 것**: 최근 완료 최대 3개. 기록 근거 문장만 — 실패 후 고쳐서 성공했으면 "고쳐서 도착했어요", 아니면 "도착했어요". [다시 해 보기]
   - **다시 보고 싶어요**: 아이가 담은 퍼즐(결과 창·목록 카드에 "다시 보고 싶어요" 토글 추가 → 기존 `reviewChanged` 이벤트) + 최근 미완료 퍼즐로 최대 3개. [해 보기]·[빼기]
   - **다음 한 걸음**: 열린 첫 미완료 퍼즐 하나 [이어하기]
   - 기록 시작 전 진행만 있는 사용자: "예전 기록은 해낸 퍼즐만 보여요." 한 줄
3. **아이 화면에 보이지 않을 것**: 실패 횟수, 힌트 사용 수, 시간, 다른 아이와 비교, 점수. "배웠다"는 완료 의미로만(숙달 판정 금지).
4. 문구(Claude 작성, 그대로):
   | 키 | ko | en |
   |---|---|---|
   | 버튼·제목 | 내 배움 | My Learning |
   | 해낸 수 | 지금까지 퍼즐 {count}개를 해냈어요 | You've solved {count} puzzles so far |
   | 도구 | 배워 본 도구 | Tools you've tried |
   | 하는 중 | 하는 중 | In progress |
   | 최근 | 최근 해낸 것 | Recently solved |
   | 고쳐서 | 고쳐서 도착했어요 | Fixed it and got there |
   | 도착 | 도착했어요 | Got there |
   | 다시 해 보기 | 다시 해 보기 | Try again |
   | 다시 보고 싶어요 | 다시 보고 싶어요 | Want to try again |
   | 해 보기 / 빼기 | 해 보기 / 빼기 | Try it / Remove |
   | 다음 한 걸음 | 다음 한 걸음 | Next step |
   | 예전 기록 | 예전 기록은 해낸 퍼즐만 보여요. | Older records only show solved puzzles. |
   | 비어 있음 | 아직 해낸 퍼즐이 없어요. 첫 퍼즐부터 해 볼까요? | No puzzles solved yet. Want to start with the first one? |
5. 세 월드 테마 적용, 1280/375/360에서 가로 스크롤·겹침 없음, 버튼 44px(큰 버튼 48px), 대비 3:1, 이모지 금지(SVG 기호), 키보드 순서·제목 구조(h1→h2), 화면 낭독 이름.
6. 단위 테스트: 집계 → 화면(빈 상태, 기록 전 사용자, 고쳐서 성공 문장, 다시 보기 담기/빼기 이벤트, 12단원 카드 상태), ko/en.
