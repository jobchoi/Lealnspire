# T27 지시서 — 정적 배포 준비 (구현 Codex, 배포 빌드 E2E·QC Claude)

같은 작업 트리(`feature/T14-t13-polish`). 먼저 docs/PROJECT_MAP.md, CLAUDE.md, docs/ROADMAP.md 라운드 2, docs/TASKS.md의 T27을 읽는다. **실제 배포·원격 설정은 하지 않는다**(사용자 승인 필요).

참고 문서(Claude가 Context7로 확인, Vite v8.0.10): 하위 경로 배포는 `base` 설정 또는 `vite build --base=/경로/`, 동적으로 이어 붙이는 URL은 `import.meta.env.BASE_URL`(정확히 이 표현으로 써야 빌드 시 치환), `vite preview --base`.

## 할 일
1. 하위 경로(예: `/lealnspire/`)에서도 동작하도록 앱 코드에 루트 고정 경로(`"/..."`로 시작하는 자산·링크·fetch)가 없는지 확인하고, 필요한 곳은 `import.meta.env.BASE_URL` 사용. vite.config.ts의 기본 base는 '/' 유지(배포 시 CLI로 지정).
2. 교사·보호자 안내 연결(T26): docs/GUIDE.md 내용을 그대로 옮긴 정적 페이지 `public/guide.html`(한국어, 외부 자원 없음, 인쇄 시 잘리지 않는 단순 스타일, 앱으로 돌아가는 링크는 상대 경로 `./`). 홈의 "내 기록 안내" 대화 상자에 "교사·보호자 안내" 링크(`${import.meta.env.BASE_URL}guide.html`, 같은 탭, 44px+, 키보드 접근). GUIDE.md와 guide.html 내용이 어긋나지 않게 단위 테스트로 핵심 문장 몇 개(예: "8개를 성공하면 1단원 완료", "이 기기의 브라우저에만")가 양쪽에 있는지 검사.
3. `docs/DEPLOY.md`: 정적 호스팅 공통 절차(빌드 명령 `npm run build -- --base=/경로/`, dist 업로드, 하위 경로·캐시 주의), 게시 전 체크리스트(verify, e2e, e2e:prod 루트·하위 경로, 외부 요청 0, 콘솔 오류 0, guide.html 열림), 되돌리기 절차(이전 dist 보관·재업로드), **기록은 도메인·경로마다 따로 저장됨**(경로를 바꾸면 사용자 기록이 안 보임) 주의.
4. `docs/ASSETS.md`: 자체 포함 글꼴 5종(@fontsource 패키지, 각 글꼴의 라이선스 — node_modules의 패키지 LICENSE/README에서 확인해 정확히 적기), SVG는 자체 제작, 외부 이미지·CDN 없음.

## 하지 말 것
원격 배포·GitHub Pages 설정·워크플로 추가, package.json·e2e·playwright 설정 수정(Claude가 함), 새 의존성, 커밋·push, TASKS/NEXT_SESSION/WORK_HISTORY 수정.
