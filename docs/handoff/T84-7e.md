## 구현
1. 이력 v2에 **단원 미소속 프로젝트 활동**(activityKind `project`) 이벤트 추가: projectCreated·projectOpened·projectEdited(실행·저장·이탈 시점에 요약 — 시작 상태/코드 변경 여부·변경 횟수·블록 종류별 수)·projectRunStarted·projectRunEnded(끝까지 실행·사용자 정지·조작 오류 종류·안전 상한)·projectSaved(실제 저장 성공한 저장본 id만)·projectClosed(미저장 여부)·projectDeleted. 이벤트에 **이름·코드·시작 상태·실행 프레임을 넣지 않음**. 실행 종료는 아이가 실제로 재생해서 본 지점 기준(계산만 하고 나간 실행은 종료로 기록하지 않음). 이력 형식 변경이 기존 v2 읽기와 호환되지 않으면 이력 v3로 올리고 v2 원본 보존(규칙).
2. 집계: 프로젝트 활동은 퍼즐 완료율·연속 실패·도움 사용·살펴볼 퍼즐에 섞지 않음. 실행량으로 창의성·실력 점수화 금지.
3. 내 배움: "공장 프로그램을 만들었어요", "저장한 작품을 다시 고쳤어요"처럼 기록에 근거한 사실 카드(수치 없음).
4. 관리자: "공장 활동" 영역 — 작품 수, 최근 활동일, 실행·저장·재방문 횟수, 실제 실행된 블록 종류(코드에 있기만 한 것과 구분), 조작 오류 종류(어른용 설명), 활동 추정 시간. 좁은 화면 카드.
5. 작품 저장은 성공했는데 이력 저장만 실패하면 작품을 보존하고 이력 누락 표시.
6. 단위 테스트: 이벤트 순서(만들기→편집→실행→정지→저장→닫기), 계산만 하고 이탈=종료 아님, 이름·코드 미포함, 퍼즐 집계 불변, 내 배움·관리자 표시, 삭제 뒤 "삭제된 작품".
