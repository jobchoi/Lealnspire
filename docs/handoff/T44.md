# T44 지시서 — 함수 Model과 저장 (구현 Codex, 설계·QC Claude)

브랜치 `feature/T44-functions`(v1.3.1 위). 먼저 docs/ROADMAP.md 라운드 3(함수 행: "정의하면 바로 실행된다", "한 번만 쓸 수 있다" 오해, 함수 카드·호출 표시, 재귀 금지), docs/PROJECT_MAP.md, CLAUDE.md, src/model/ProgressRepository.ts(v2의 `functions: []` 자리)를 읽는다. [제안·잠정]. **이번엔 Model·저장만**(화면·스테이지는 T45).

## 설계 (Claude 확정)
- 프로그램 문서 `{ main: Block[], functions: FunctionDef[] }`. `FunctionDef = { id: string; icon: 'star' | 'moon' ; body: Block[] }` — 이름은 글자 입력 없이 그림 카드 두 종(별·달)만, 함수는 **최대 2개**.
- 호출 블록 `{ id, type: 'call', fn: string }`(fn = FunctionDef.id). **함수 몸체 안에는 call을 넣을 수 없음**(재귀·상호 호출 원천 차단, 검증에서 거부).
- 실행: main을 실행하다 call을 만나면 그 함수 body를 실행하고 돌아옴. 정의만 있고 호출이 없으면 아무 일도 안 함(오해 퍼즐용). 호출 블록 자체는 프레임을 만들지 않되, 함수 body의 각 프레임에 `call?: { callId, fn }`(실행 중인 호출)을 넣어 화면이 "어느 호출에서 실행 중인지" 보여 줄 수 있게. 회차(loops)·검사(check)·실패 지점은 함수 안에서도 정확(실패 지점은 함수 body 안 블록 + 그 호출 ID).
- 블록 수: main + 모든 함수 body의 블록 합(호출 1개 = 1블록, 함수 정의 자체는 0). 상한 10 그대로.
- 편집 도우미(순수): 함수 만들기(빈 body, 다음 아이콘), 함수 지우기(그 함수를 부르는 call도 함께 제거 — 되돌리기로 복구 가능하게 Controller가 문서 전체를 기록), 함수 body에 넣기·이동·삭제·복제·ID 재발급(main과 공통), 존재하지 않는 fn을 부르는 call은 검증에서 거부.
- 실행기 API: `run(stage, doc)`/`runAll(stage, doc)`가 문서를 받도록(기존 Block[] 호출은 `{ main, functions: [] }`로 감싸 호환). 1·2·3단원 결과 불변(고정 fixture 회귀).
- 저장: **v2 그대로**(functions 자리가 이미 있음). 검증만 확장: functions 배열(최대 2, id 중복 금지, icon 허용 목록, body 검증, body에 call 금지), main의 call은 존재하는 fn만, 전체 노드·깊이 상한은 main+functions 합산. v1.3.1 이하 앱이 함수가 든 코드를 읽으면 그 스테이지 코드만 비워지고(T36 손상 격리) 완료·별은 유지됨 — RELEASE·CHANGELOG에 롤백 주의로 적을 것.
- Controller: GameController·EditorController가 문서(main+functions)를 다루도록 최소 변경, 되돌리기(T19)는 문서 단위, 화면은 지금처럼 main만 보여도 됨(T45에서 함수 패널).

## 테스트 (단위)
정의만 하면 실행 안 됨, 같은 함수 여러 번 호출(두 번 호출 시 같은 동작 두 번), 함수 안 repeat·if·while, 호출 안 실패 지점·회차, 함수 지우기 시 call 제거·되돌리기, 재귀(함수 body 안 call) 거부, 없는 fn 거부, 블록 수 합산·상한, 저장 왕복(v2), 손상 격리, 1~3단원 회귀.
