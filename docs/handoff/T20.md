# T20 지시서 — 내 기기에 저장되는 기록 안내·삭제 (구현 Codex, QC Claude)

같은 작업 트리(`feature/T14-t13-polish`). 먼저 docs/PROJECT_MAP.md, CLAUDE.md, docs/ROADMAP.md, docs/TASKS.md의 T20을 읽는다. [제안·잠정] 작업.

## 목적
보호자·사용자가 무엇이 어디에 저장되는지 알고, 원하면 지울 수 있게 한다(데이터 수집 우려 대응). 감시·통계 화면은 만들지 않는다.

## 할 일
1. 홈 화면에 작은 정보 버튼(기호: 원 안의 i 또는 자물쇠, aria-label "내 기록 안내", 44px+). 누르면 대화 상자(role=dialog, aria-modal, Esc로 닫기, 포커스 가두기 — 기존 ResultModal 방식 재사용 가능).
2. 안내 문구(ko.json, 실제 저장 구조와 일치해야 함 — src/model/ProgressRepository.ts 확인):
   - "이 기기의 브라우저에만 저장돼요. 서버로 보내지 않아요."
   - "저장하는 것: 깬 스테이지, 스테이지별 최고 별, 스테이지별 마지막으로 만든 블록."
   - "브라우저 기록을 지우면 함께 사라져요."
   과장 금지("아무것도 저장하지 않아요" 등).
3. "기록 지우기" 버튼 → 한 번 더 확인("정말 지울까요? 되돌릴 수 없어요." + "지우기"/"취소"). 확정 시 ProgressRepository를 통해 이 앱의 키(lealnspire.progress)만 삭제(다른 키·다른 앱 데이터 건드리지 않음), 홈 상태 갱신(이어하기 버튼 사라짐 등). 취소 시 보존.
4. 저장소를 쓸 수 없는 환경(storage 없음·예외)에서도 안내는 보이고, 지우기는 오류 없이 안내 문구("이 브라우저에서는 저장하지 않고 있어요")로 처리.
5. ProgressRepository에 clear 메서드 + 단위 테스트(다른 키 보존, 예외 storage), 홈/대화 상자 컴포넌트 테스트.
6. 세 월드 톤은 필요 없음(홈 톤 유지). 375×667·360×560에서 대화 상자가 화면 안, 버튼 44px+, 글자 잘림 없음.

## 하지 말 것
localStorage를 ProgressRepository 밖에서 직접 쓰기(CLAUDE.md 규칙), 저장 형식 변경, 통계·감시 화면, e2e·package 수정, 새 의존성, 커밋·push, TASKS/NEXT_SESSION/WORK_HISTORY 수정.

## 검증
`npm run verify`. 포트 불가 시 E2E·브라우저 미검증. Claude가 e2e(일부 완료 → 삭제 취소 → 유지 → 삭제 확정 → 새로고침 후 초기 상태, 다른 키 보존)를 추가한다.
