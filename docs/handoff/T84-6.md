# T84-6 지시서 — 완료 도장 + 선택 도전(데이터로 확장 가능) (구현 Codex, 기획 GPT, 결정 사용자, 문구·E2E·QC Claude)

브랜치 `feature/T84-6-stamps-challenges`(develop 최신 = v1.22.0). 먼저 docs/design/stars-and-projects.md(**사용자 결정 표 = 기준**, 원문 "가" 절), docs/design/learning-history.md, CLAUDE.md(저장 규칙)를 읽는다. [제안·잠정].

## 구현
1. **완료 도장**: 성공(모든 변형 통과 + 마지막 프레임)하면 모든 퍼즐에 도장(둥근 도장 + 로봇·체크 SVG + "해냈어요"). 결과 창·목록 카드·게임 화면의 별 표시를 도장으로 교체. 미완료에 빈 도장·빈 별 칸 없음. 개방·완주 조건은 지금처럼 completed만.
2. **선택 도전 레지스트리**(`src/model/challenges.ts`): `{ stageId, id, kind, ruleVersion, params }[]` 데이터 한 곳. 판정 함수는 kind별(`shorter`: `FunctionProgram.count() ≤ params.maxBlocks` + 모든 변형 성공, `bothTurns`: 실제 실행한 회전으로 오른쪽만 성공·왼쪽만 성공을 각각 확보, `bothDirections`: 실제 비교한 순회 방향 앞·뒤 각각 성공). **첫 샘플 3개**: `2`(bothTurns), `u2-1`(shorter, 4), `u11-1`(bothDirections). 레지스트리에 항목을 추가/삭제하면 화면·저장·집계가 따라오게(하드코딩 금지). `u12-1` 두 전략 판정은 이번에 넣지 않음.
3. 도전 표시: 완료 뒤 게임 화면에 "더 해 볼까?" 버튼으로 목표 펼침(완료 전 숨김), 첫 성공에도 조건 충족 시 자동 인정, 결과 창에 새로 얻은 도전만 작은 스티커, 미달성은 아무 표시 없음(실패 문구 금지). 목록 카드에 얻은 도전 기호.
4. **저장**: 진행 **v4**(v3 원본 보존 — 지금 v1·v2 원본 보존과 같은 방식) — `bestStars`는 동결·보존(`legacyEvaluationVersion: 1`), `completionEvaluationVersion: 2`, `challenges: { [challengeId]: { ruleVersion, achievedAt, partial?: string[] } }`. 읽기·정규화·복사·편집 저장·완료 저장 모든 경로에서 새 필드 보존. 이력 **v2**: 별 없는 `completionConfirmed`, `challengeAchieved`(이전 v1 이벤트는 그대로 읽음).
5. 내 배움: 최근 도전 달성을 사실 문장으로("짧게도 풀어 봤어요"/"양쪽으로 돌아 봤어요"/"앞과 뒤에서 찾아 봤어요"), 점수·달성률 없음. 접힌 "이전 별 기록"(예전 방식 별 안내). 관리자: 완료와 도전을 별도 열, 도전 미달성은 살펴볼 퍼즐 조건 아님.
6. 문구(Claude 작성, 그대로): 도장 "해냈어요"/"Done!", 도전 버튼 "더 해 볼까?"/"Want a challenge?", 도전명 shorter "블록 {max}개 안에 풀기"/"Solve with {max} blocks or fewer", bothTurns "왼쪽으로도, 오른쪽으로도 돌아서 풀기"/"Solve it turning left, and turning right", bothDirections "앞에서도, 뒤에서도 찾아서 풀기"/"Solve it searching from the front, and from the back", 달성 "도전 성공!"/"Challenge done!", 부분 "하나 했어요. 다른 쪽도 해 볼까요?"/"One done. Try the other way?", 이전 별 "예전 방식으로 받은 별이에요. 지금은 도장과 도전으로 보여 줘요."/"Stars from the old way. Now we show stamps and challenges."
7. 단위 테스트: 레지스트리 항목 추가/삭제만으로 동작, 샘플 3개의 달성·미달성 성공·실패·반례(실행 안 되는 회전/순회 블록 불인정), 첫 성공 자동 인정, 이탈 시 미인정, 중복 확정 방지, 힌트·실패·시간과 무관, v3→v4 이행·필드 왕복·손상 격리·삭제, 완주가 도전과 무관.
