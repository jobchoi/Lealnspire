# T77 지시서 — 함수 탭에서도 작업 공간 힌트 강조 (구현 Codex, 점검 GPT, E2E·QC Claude)

브랜치 `feature/T77-hint-function-tab`(develop 최신 = v1.16.0). 먼저 CLAUDE.md, docs/design/hints.md(T74), `~/project/_progress/logs/product-audit2-gpt.md` 2절 "작은 화면에서 함수 몸체에는 작업 공간 힌트 강조가 닿지 않음"을 읽는다. [제안·잠정].

## 문제
힌트 focus가 `workspace`일 때 `data-hint-focus`가 main 작업 공간(`.workspace-shell`)과 함수 탭 줄에만 붙는다. 좁은 화면(≤700px)에서 함수 탭을 열면 main 패널이 숨겨져(`index.css` functions-page 규칙) 지금 보고 있는 함수 몸체(`.function-body`)에는 강조가 없다. 넓은 화면에서도 함수 카드는 강조 밖이다.

## 구현
1. focus가 `workspace`이면 함수 몸체(`.function-body`)에도 같은 강조(`data-hint-focus="workspace"`). 넓은 화면은 main·함수 몸체 모두, 좁은 화면은 보이는 쪽이 강조된 상태가 된다.
2. 자동 탭 전환·선택 변경·코드 변경 없음. 실행 중 강조(function-active)·삽입 대상(function-target)·실패 표시를 덮지 않음(테두리 방식 유지).
3. 단위 테스트: 4·7단원 스테이지에서 workspace focus일 때 함수 몸체에 강조, 힌트 닫으면 해제, 탭·코드·선택 불변.

## 하지 말 것
