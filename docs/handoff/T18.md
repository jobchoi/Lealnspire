# T18 지시서 — 반복 회차 표시 (구현 Codex, QC Claude)

같은 작업 트리(`feature/T14-t13-polish`). 먼저 docs/PROJECT_MAP.md, CLAUDE.md, docs/ROADMAP.md, docs/TASKS.md의 T18을 읽는다. [제안·잠정] 작업.

## 목적
반복 블록이 "몇 번째 도는 중인지" 실행하면서 보이게 해, 같은 블록이 여러 번 실행되는 이유를 눈으로 따라가게 한다.

## 할 일
1. Model(순수 TS): Frame에 현재 실행 중인 반복들의 회차 정보를 추가한다. 예: `loops?: { blockId: string; iteration: number; count: number }[]`(바깥→안쪽 순). 기존 필드·의미·결과는 그대로. 빈 반복(몸체 없음)은 프레임을 만들지 않는 현재 동작 유지, 단계 상한에서도 정보가 일관됨. 단위 테스트: 단일 반복, 중첩 반복(2[F 3[L]]), 반복 뒤 블록에서 정보가 비어 있음, 충돌로 중간 종료.
2. View: 재생 중(또는 한 단계 실행 중) 현재 프레임의 각 반복 타일에 "현재/전체" 회차를 표시(예: 2/3). 세 월드 표현(스케치북: 크레용 숫자, 기차: 바퀴 수 표지, 게임기: LCD 숫자)으로, 반복 횟수 글자와 구분되게. 실행이 끝나거나 처음으로 가면 표시가 사라진다. 스크린리더용으로 반복 타일 aria-label은 그대로 두고, 회차는 별도 요소에 aria-label "3번 중 2번째"(ko.json) 정도.
3. 작은 화면(360×560)에서 회차 표시가 타일 밖으로 나가거나 글자가 잘리지 않음(e2e 레이아웃 검사 기준: 버튼 안 글자 위치).
4. 저장 형식·편집 동작 불변.

## 하지 말 것
게임 규칙·저장 형식 변경, e2e·package 수정, 새 의존성, 커밋·push, TASKS/NEXT_SESSION/WORK_HISTORY 수정.

## 검증
`npm run verify`. 포트 불가 시 E2E·브라우저는 미검증. 회차 정보 계산 규칙을 보고. Claude가 e2e(반복을 한 단계씩 실행하며 1/3→2/3→3/3, 끝나면 사라짐)를 추가한다.
