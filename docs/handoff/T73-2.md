# T73-2 지시서 — 첫 사용 시범: 나머지 개념 장면 (구현 Codex, 기획 GPT, 확정·E2E·QC Claude)

브랜치 `feature/T73-onboarding`(T73-1 위). 먼저 docs/design/onboarding-demos.md(**장면 표 = 기준**), docs/handoff/T73-1.md(기반 계약), CLAUDE.md를 읽는다. T73-1의 DemoController·DemoModal·설정 v2 본 기록을 그대로 확장한다. [제안·잠정].

## 구현
1. 설계 표의 나머지 시범을 추가(각 3~4컷, 예시 맵·숫자·코드는 **실제 퍼즐과 다르게** — 정답·필요 횟수·고칠 블록을 공개하지 않음):
   로봇 기준 회전(1단원 2번), 반복 안에 넣기(1단원 5번), 조건(2단원 첫 진입), else(2단원 5번), while(3단원 첫), 함수 만들기·부르기(4단원 첫), 상자 A(5단원 첫), 논리 조건 편집(6단원 첫), ◆ 매개변수(7단원 첫), return(8단원 첫), on 처리기(9단원 첫), 리스트 ▣(10단원 첫), 탐색 멈추기(11단원 2번). 12단원은 없음.
2. 제안 조건은 T73-1과 같음: 그 스테이지에서 아직 편집 전·실행 중 아님·결과 창 아님일 때 "손+▶" 버튼, 본 시범은 강조 없이. 시범 식별자별로 본 기록.
3. 컷마다 한 번 낭독(ko/en, 행동·결과 한 문장). 장식은 낭독 제외. 동작 줄이기면 정지 컷 + 이전/다음.
4. **정답 유출 방지 테스트**: 각 시범의 예시 맵·프로그램이 해당 진입 스테이지의 맵·정답(solution·solutionFunctions)과 같지 않음을 단위 테스트로 단언. 시범 재생 전후 진행 불변(T73-1 테스트 확장).
5. 세 월드 × 1280/375/360에서 시범 창이 화면 안, 버튼 44px(시범 버튼 48px), 대비 3:1, 이모지 금지.

## 문구
컷 낭독 문장은 장면 표의 컷 설명을 아이에게 맞는 한 문장으로(해요체). en은 같은 뜻의 짧은 문장. 개념어(`repeat`, `if`, `else`, `while`, `function`, `set`, `not/and/or`, `return`, `on`, `list`)는 영어 그대로.

## 하지 말 것
자동 팝업, 정답 장면, 진행 저장 형식 변경, package·의존성, 커밋·push, TASKS/NEXT_SESSION/WORK_HISTORY·CHANGELOG·GUIDE·public, E2E 파일(Claude).
