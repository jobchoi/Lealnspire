# T41 지시서 — `if / else` (구현·맵 설계 Codex, 기준·E2E·QC Claude)

브랜치 `feature/T41-else`(v1.1.0 위). 먼저 docs/design/unit2-conditions.md, docs/ROADMAP.md 라운드 3(GPT 분해표의 else 행: "두 가지를 순서대로 실행한다" 오해), docs/PROJECT_MAP.md, CLAUDE.md, src/i18n/glossary.json(else 항목)을 읽는다. [제안·잠정].

## 배울 것
조건이 거짓일 때 할 일을 따로 정한다. 두 가지 중 **하나만** 실행된다.

## Model (순수 TS)
- if 블록에 선택적 `else?: Block[]`(없으면 지금과 동일). 검사 1회 → 참이면 body, 거짓이면 else(있으면). 검사 프레임의 check에 어느 가지를 탔는지 포함 가능.
- 편집 도우미: if에 else 추가/제거(제거 시 else 안 블록 수만큼 블록 수 감소 — 되돌리기로 복구 가능), else 안에 넣기·이동·삭제·복제·ID 재발급, countBlocks(else 블록 자체는 세지 않고 안의 블록만 셈 — if 1개 + 양쪽 블록).
- 저장 v2 검증: else 허용(배열, 깊이·노드 상한 동일). 형식 버전은 그대로 v2.
- runAll·실패 지점·회차는 else 안에서도 정확.

## 화면
- 선택한 if의 작업 막대에 "else 추가"/"else 빼기"(aria-label ko "else 추가", en "Add else"), else가 있으면 if 감싼 영역 안에 `if` 가지와 `else` 가지를 위아래(좁으면)·좌우로 나눠 표시, `else` 라벨은 glossary 키워드. 추가 대상 선택: if 가지 "안에 넣기", else 가지 "else 안에 넣기"(aria "…else 안에 넣기"), 추가 위치 안내도 구분.
- 실행: 탄 가지 강조, 안 탄 가지 흐림 + "건너뜀". 센서 문구는 T38 그대로.
- 세 월드·세 화면 크기 배치 기준, 영어 키 일치, 개념어 하드코딩 금지.

## 스테이지 (맵은 Codex가 설계하되 아래 조건을 **테스트로 증명**)
- u2-5, u2-6 두 개(2단원 뒤에 이어짐, world는 u2-5 train, u2-6 handheld). 각 2~3개 변형 맵, 크기 6×6 이하, startDir 자유.
- 조건: (a) 정답(else 사용)이 모든 변형 성공, (b) **else 없는 모든 프로그램**(if는 허용, 블록 maxBlocks 이하)이 모든 변형을 동시에 풀지 못함 — T39의 상태 변환 합성 전수 탐색을 if·else까지 확장해 증명, (c) 모든 통행 칸이 의미 있게 쓰임.
- 추천 정답 모양: `repeat N [ if 막힘 [ 돌기 ] else [ 앞으로 ] ]` 계열(막히면 그 자리에서 돌고, 열려 있으면 간다 — 한 반복에 하나만). if만 쓴 `repeat N [ if 막힘 [돌기], 앞으로 ]`가 실패하려면 "돌고 나서도 바로 앞이 막힌" 곳(연속 회전이 필요한 곳)이 있어야 한다.
- 제목·목표·힌트 ko/en은 Codex가 초안을 쓰고(정답 순서를 말하지 않는 질문형, T16 기준) 보고에 적을 것 — Claude가 검토·수정한다.
- 2단원 완주 문구는 u2-6 성공 시로 옮긴다(u2-4 성공 시엔 "다음 스테이지").
- 예측 도전 하나(선택): `if 막힘 [R] else [F]`를 한 번만 실행하는 코드로 "두 가지가 모두 실행된다" 오해를 드러내는 후보 포함.
