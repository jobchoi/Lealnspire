# T35 지시서 — 1단원 영어 완성 (번역 Claude, 구현 Codex, QC Claude)

브랜치 `feature/T33-unit2-plan`. 먼저 docs/PROJECT_MAP.md, CLAUDE.md, docs/ROADMAP.md 라운드 3(개념어·언어 방침), docs/GAME_DESIGN.md 11절을 읽는다. [제안·잠정].

## 이미 된 것 (Claude)
- `src/i18n/locales/en.json`: ko의 모든 키(182개)와 치환 인자를 맞춘 전체 영어 번역(용어집 기준, 아이 눈높이). **문구를 바꾸지 말 것** — 배치 때문에 꼭 줄여야 하면 바꾸지 말고 보고에 적어라(Claude가 고침).
- `public/guide-en.html`: 영어 교사·보호자 안내(앱 복귀 링크 `./?lang=en`, "언어 버튼"을 언급함).

## 할 일 (Codex)
1. en을 **공식 지원 locale**로: T34의 키·치환 인자 검사에서 en을 ko와 완전 일치 대상으로(부분 locale 아님). I18n.ts 주석 갱신.
2. 언어 선택: 홈 화면에 언어 버튼(`한국어 / English` 토글, 기호 🌐 대신 SVG 지구 아이콘, aria-label "언어 바꾸기 / Change language", 44px+). 우선순위: URL `?lang=` → 저장된 선택 → 기본 ko. 선택은 저장해 다음 방문에도 유지 — **localStorage는 ProgressRepository(주입된 storage)를 통해서만**(CLAUDE.md). 진행 기록 키와 분리된 키(예: `lealnspire.settings`, `{ version: 1, lang }`)로, 기록 삭제(T20)는 진행 기록만 지우고 언어 설정은 유지할지 함께 지울지 결정해 보고(추천: 진행 기록만 삭제, 안내 문구는 그대로 맞는지 확인).
3. `<html lang>`을 현재 언어로, 문서 제목도 언어에 맞게.
4. 기록 안내 대화 상자의 안내 링크: en이면 `${import.meta.env.BASE_URL}guide-en.html`, ko면 guide.html. GUIDE와 안내 페이지 핵심 문장 일치 테스트에 영어판도 추가(guide-en.html의 핵심 문장 몇 개가 존재하는지).
5. 화면에 하드코딩된 한국어·영어 문구가 남아 있지 않은지 점검(장식용 `BATTERY · CODE BOY`, `STAGE` 등 월드 장식은 예외로 목록화해 보고).
6. 영어 화면에서 배치 기준(세 월드 × 3개 화면 크기, 스크롤 없음, 44px, 글자 잘림·쪼개짐 없음)이 깨지지 않게 CSS 보정(글자 크기를 줄여 맞추지 말 것). Claude가 영어 e2e로 확인한다.
