## 할 일
1. handheld 버튼(및 같은 회색 계열을 쓰는 모든 요소) 글자 대비 4.5:1 이상. 아이콘 3:1 이상. 게임기 느낌은 유지(더 어두운 회색 바탕 또는 진한 글자).
2. 맵 aria-label: "{제목} 지도, 로봇은 {줄}번째 줄 {칸}번째 칸에서 {방향}을 봐요. 별은 {줄}번째 줄 {칸}번째 칸." 형식(ko.json). 재생 중 위치가 바뀌면 갱신. 세 월드 모두. 결과(부딪힘·도착)는 기존 role=status/대화 상자로 충분.
3. 배경 이미지·그라데이션 위 글자(스케치북 줄 공책, 기차 하늘·풀밭, 홈 카드)는 자동 계산이 안 되므로, 각 글자 색과 실제 뒤 배경색(가장 밝은/어두운 지점) 기준으로 직접 계산해 4.5:1 미만인 곳을 고치고 보고에 표로 적어라.
4. 남은 사소 항목: 375px에서 '다음 힌트' 버튼 글자가 두 줄로 쪼개짐 → 한 줄. 재생 중 편집 잠금 시 타일이 모두 회색이 되어 블록 색 구분이 사라짐 → 색은 유지하고 잠금은 투명도·커서·aria-disabled로 표시(아이콘 3:1 유지).
