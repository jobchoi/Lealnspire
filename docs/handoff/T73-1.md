# T73-1 지시서 — 첫 사용 시범: 기반 + 첫 시범 "블록 추가 → 실행" (구현 Codex, 기획 GPT, 확정·E2E·QC Claude)

브랜치 `feature/T73-onboarding`(develop = v1.13.0 위). 먼저 docs/design/onboarding-demos.md(**설계 전부**), docs/GAME_DESIGN.md 8절(저학년 UX), CLAUDE.md, docs/PROJECT_MAP.md를 읽는다. [제안·잠정]. 이번 범위는 **기반과 첫 시범 하나**(나머지 시범은 T73-2).

## 구현
1. **요청형 제안**: 시범이 있는 순간에 작은 "손 + ▶" 시범 버튼만 보여 줌(자동 팝업 금지). 첫 시범은 1단원 1번(첫 편집 전)에서 "블록 추가 → 실행". 실행 중·결과 창 위에서는 열리지 않음. 버튼 48×48 이상, aria ko "어떻게 하는지 보기" / en "See how it works".
2. **미니 장면**: 실제 퍼즐과 다른 작은 예시 맵(예: `S.G`가 아닌 별도 2~3칸 맵)에서 3~4컷: 앞으로 기호 누름 → 작업 공간에 블록 생성 → ▶ 누름 → 해당 블록 강조와 로봇 한 칸 이동. 기존 Board·BlockTiles·실행기를 재사용하되 **실제 진행 저장소·GameController와 연결하지 않음**(코드·별·완료·잠금 불변). 시범 데이터는 정규 스테이지 목록 밖.
3. **재생 제어**: 컷당 약 2~3초, 마지막 컷에서 멈춤(반복 재생 없음), 건너뛰기·닫기·다시 재생·일시정지, 동작 줄이기면 정지 컷 + 이전/다음. 닫기·화면 이탈 시 타이머 정리, 연타해도 모달 하나.
4. **본 기록**: 완료하거나 건너뛰면 그 시범의 제안 버튼을 다시 강조하지 않음(버튼은 작게 남겨 다시 볼 수 있게 해도 됨 — 설계 원칙 "다시 안 뜸"은 자동 강조 기준). `lealnspire.settings`를 **버전 2**로 올리고 v1(언어만)을 이행, `saveLanguage`가 설정 전체를 덮어쓰지 않게 언어·본 시범 목록을 합쳐 저장. 손상 목록은 빈 목록으로 복구·언어 보존. 저장 차단 시 같은 세션 동안만 기억. 진행 기록 지우기는 설정을 건드리지 않음.
5. **홈 설정 "시범 다시 보기"**: 본 기록 초기화(확인 후). 
6. **접근성**: 모달 포커스 진입·복귀, 탭 순환, Esc 닫기, 배경 조작 차단, 컷마다 한 번 낭독(ko "앞으로 블록을 눌렀어요" → "작업 공간에 블록이 생겼어요" → "실행을 눌렀어요" → "로봇이 한 칸 움직였어요", en 대응). 장식 손은 낭독 제외.
7. 단위 테스트: 설정 v1→v2 이행·손상 복구·언어 변경이 본 기록을 지우지 않음, 시범 재생이 진행 저장소를 바꾸지 않음, 타이머 정리.
