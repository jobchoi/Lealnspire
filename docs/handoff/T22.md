# T22 지시서 — 결과 창을 닫은 뒤 바로 편집 (구현 Codex, QC Claude)

같은 작업 트리(`feature/T14-t13-polish`). 먼저 docs/PROJECT_MAP.md, CLAUDE.md, docs/TASKS.md의 T22를 읽는다. [제안] 작업.

## 현상
실행이 끝나고 결과 창을 "닫기"로 닫으면 재생 상태가 finished로 남아 팔레트·블록 편집이 잠긴다(locked). "처음으로"를 눌러야 편집된다. 아이는 왜 블록이 안 눌리는지 모른다(T16 E2E 작성 중 Claude가 발견).

## 할 일
1. 재생이 끝난(finished) 상태에서는 편집을 잠그지 않는다. 팔레트·블록·작업 막대를 누르면 먼저 재생을 처음으로 되돌린(로봇 출발점, 실패 표시 제거) 뒤 그 편집을 적용한다. 한 번 누름으로 편집까지 된다.
2. 재생 중(playing)이거나 한 단계 실행 도중(시작했지만 끝나지 않음)의 잠금은 지금처럼 유지한다. 한 단계 실행 도중의 동작은 바꾸지 말 것.
3. Controller 단위 테스트: finished 후 추가·삭제·횟수 변경이 즉시 적용되고 재생이 초기화됨, playing 중에는 거부.
4. 기존 E2E 계약 유지. 특히 journeys의 "실행 중에는 편집할 수 없고 … 처음으로 누르면 다시 편집 가능" 시나리오가 계속 맞아야 한다(재생 중 잠금).

## 하지 말 것
게임 규칙·저장 형식 변경, e2e·package 수정, 새 의존성, 커밋·push, TASKS/NEXT_SESSION/WORK_HISTORY 수정.

## 검증
`npm run verify`. 포트 불가 시 E2E·브라우저는 미검증. Claude가 e2e(실패 → 닫기 → 바로 블록 추가 → 성공)를 추가한다.
