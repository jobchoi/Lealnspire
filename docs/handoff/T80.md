# T80 지시서 — 스테이지 제목 번호 표기 통일 (구현 Codex, 점검 GPT, E2E·QC Claude)

브랜치 `feature/T80-title-numbers`(develop 최신 = v1.18.0). 먼저 CLAUDE.md와 `~/project/_progress/logs/product-audit2-gpt.md` 1절 "제목 번호 표기 혼재"를 읽는다. [제안·잠정].

## 문제
게임 화면 제목(h1)이 단원마다 다르다. 1단원은 화면이 "스테이지 1: 첫걸음"처럼 앞에 붙인다. 2~5단원은 일부 문구에 "2단원 1: …"이 들어 있고(u21·u25·u26·u3x·u4x·u5x) 일부는 없다(u22·u23·u24). 6~12단원은 번호가 없다. en도 같다("Unit 2-1: …").

## 구현
1. 2~12단원 스테이지 제목 문구(ko/en `u<단원><번호>Title`)에서 "N단원 M: " / "Unit N-M: " 접두를 모두 뺀다(제목 자체만 남김).
2. 게임 화면 h1은 2~12단원이면 화면에서 접두를 붙인다: 새 키 `unitStageLabel` ko "{unit}단원 {number}: " / en "Unit {unit}-{number}: ". 단원·번호는 스테이지 id(`u<단원>-<번호>`)에서. 1단원("스테이지 N: ")·보너스("보너스 N: …" 문구 그대로)는 지금대로.
3. 스테이지 목록 카드: 2~12단원 카드는 단원 묶음 아래에 있으므로 "M. 제목"(ko/en 같음)으로 통일. 1단원 카드는 지금대로.
4. 결과 창 등 제목을 쓰는 다른 곳(`stageLabel` 등)도 같은 규칙으로 일관되게. 접근성 이름이 바뀌는 곳은 단위 테스트 기대를 새 규칙으로 갱신(기대값은 근거 있게).
5. 단위 테스트: 45개 정규 스테이지 h1이 단원별 같은 형식, locale 제목에 접두가 남지 않음(정규식), ko/en.
