# T84-7-라 지시서 — 공장 작품 저장본 (구현 Codex, 검토 GPT, E2E·QC Claude)

브랜치 `feature/T84-7-saves`(develop = v1.24.0). 먼저 docs/design/stars-and-projects.md의 2차 기획 5절(저장 단위·용량)과 3차 기획 5절(7-라 완료 조건·저장 상한), src/model/ProgressRepository.ts(진행 v4·이력 v2·삭제·예산), src/view/pages/FactoryPage.tsx, CLAUDE.md(저장은 ProgressRepository만)를 읽는다. [제안·잠정].

## 구현
1. **프로젝트 문서 v1**(별도 키 `lealnspire.projects.v1`, ProgressRepository 안에서만 읽기·쓰기): 작품 = 앱이 만든 id·아이가 지은 이름(최대 20자, 일반 텍스트, 중복 허용, 기본 "내 공장 1")·세계 `factory`·생성/저장 시각·저장본 목록. 저장본 = id·순번·문서/실행 규칙 버전·시작 상태·코드·함수·주문·목표 수·신호열(프레임·결과 상태 제외).
2. 명시적 저장: "저장하기" 버튼 → 새 저장본(내용이 같으면 만들지 않음), 성공했을 때만 "저장했어요". 작품당 저장본 5개 — 6번째는 지울 저장본을 아이가 고름(자동 삭제 금지). 작품 20개·프로젝트 전체 512KiB·앱 전체 2MiB 예산(기존 예산 계산에 포함), 넘으면 정리 화면 안내.
3. 화면: 공장 화면에 이름 입력("진짜 이름이나 학교 이름은 쓰지 않아도 돼요" 안내)·저장하기·저장 상태 표시, 홈 "공장 만들기" → **내 작품 목록**(카드: 이름·저장일·새로 만들기), 작품 열기(최근 저장본을 작업본으로), 이전 저장본 열기(복사해서 작업본으로), 작품 삭제(확인). 저장 안 한 변경이 있으면 나갈 때 "저장하고 나가기 / 저장하지 않고 나가기 / 계속 만들기". "나가면 사라져요" 안내 제거.
4. 저장 실패: 작업본은 메모리에 유지하고 "이 창을 닫으면 바뀐 내용이 사라질 수 있어요"(T78 계약과 같은 방식). 손상 격리: 작품 하나가 깨져도 다른 작품·진행·이력은 유지. **기록 전체 삭제**에 프로젝트 키 포함(설정 유지). 개방이 줄어든(진행 삭제) 저장본은 보존하고 실행만 막음(7-나 계약).
5. 이름·코드는 학습 이력에 넣지 않음(이력 연결은 7-마).
6. 단위 테스트: 저장/재접속 복원, 같은 내용 저장 방지, 5저장본 경계·선택 삭제, 20작품·용량 경계, 저장 실패 메모리 유지, 손상 격리, 전체 삭제, 이름 길이·제어 문자, 이전 저장본 열기 복사.
