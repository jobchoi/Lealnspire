# T81 지시서 — 영어 번호·아동 문구 정비 (구현 Codex, 점검 GPT, QC Claude)

브랜치 `feature/T81-english-wording`(develop 최신 = v1.19.0). 먼저 CLAUDE.md와 `~/project/_progress/logs/product-audit3-gpt.md` 1절 표를 읽는다. [제안·잠정].

## 구현
1. 3차 점검 1절 표의 en 문구를 그대로 반영(12행). 원칙: `{order}`는 블록 위치(`1.2` 등)이므로 "Step" 대신 "Block {order}: …". 치환 인자는 그대로 보존.
   - 단, `demo.cut2`는 실제 실행 버튼의 영어 이름(세 월드의 run 버튼 라벨)을 확인해 그 이름에 맞춘다(점검표의 "Pressed Run"은 예시).
2. 같은 번호 문제가 표 밖의 다른 en 키에도 있으면(ko가 "{order}번 블록"인데 en이 "Step {order}"인 곳) 같은 원칙으로 함께 고치고 보고에 목록을 남긴다. ko 문구는 바꾸지 않는다.
3. 단위 테스트: ko가 블록 번호를 뜻하는 키(`{order}`를 쓰는 키)는 en에 "Step"이 없고 "Block {order}"를 포함(키 목록 기반 검사). 기존 테스트의 접근성 이름 기대는 근거 있게 갱신.

## 하지 말 것
ko 문구 변경, 개념어(repeat·if·while·list 등 화면 키워드) 변경, 레이아웃, 저장 형식, package·의존성, 커밋·push, TASKS/NEXT_SESSION/WORK_HISTORY·CHANGELOG·GUIDE·public, E2E 파일(Claude — 영어 E2E가 깨질 선택자가 있으면 보고에 적기).
