## 스테이지 (2단원 통과 중심: 성공 = 별 3개)

### u2-2 (world `sketchbook`) — maxBlocks 6, solution `repeat 4 [ if 막힘 [L], F ]`
- 변형 A: `##G#`, `##.#`, `S..#`  / 변형 B: `#G##`, `#.##`, `#.##`, `S.##`
- ko: 제목 "왼쪽일 수도 있어요", 목표 "이번엔 막히면 왼쪽으로 돌아 두 맵을 지나가요.", 힌트1(강조 walls) "두 맵에서 길이 어느 쪽으로 꺾이는지 보세요.", 힌트2 "막혔을 때 하는 일만 바꾸면 될까요, 검사하는 것도 바꿔야 할까요?"
- en: "It Might Be Left", "This time, turn left when blocked to get through both maps.", "Look at which way the path bends on each map.", "Do you only need to change what happens when blocked, or what you check too?"

### u2-3 (world `train`) — maxBlocks 6, solution `repeat 5 [ if 막힘 [R], F ]`
- 변형 A: `S..#`, `##.#`, `#G.#` / 변형 B: `S.#`, `#.#`, `#.#`, `G.#`
- (A: 앞,앞,막힘→오른쪽,앞,앞,맵 끝 막힘→오른쪽,앞=도착 / B: 앞,막힘→오른쪽,앞,앞,앞,맵 끝 막힘→오른쪽,앞=도착)
- ko: "두 번 꺾는 길", "모퉁이가 두 번 있어도 같은 코드로 지나가요.", 힌트1(walls) "길이 꺾이는 곳을 모두 찾아보세요.", 힌트2 "모퉁이가 하나일 때 쓴 방법을 그대로 쓰면, 몇 번 반복해야 할까요?"
- en: "Two Turns", "Use the same code even when there are two corners.", "Find every place where the path bends.", "If you reuse your one-corner idea, how many times should it repeat?"

### u2-4 (world `handheld`) — maxBlocks 6, initialProgram `if 막힘 [R], repeat 4 [ F ]`, solution `repeat 4 [ if 막힘 [R], F ]`
- 변형 A: `S...#`, `###G#` / 변형 B: `S###`, `.###`, `.###`, `G###`
- 처음 코드는 B에서는 성공하고 A에서는 4번째 앞으로에서 부딪힌다(검사를 처음 한 번만 하므로).
- ko: "if는 계속 지켜보지 않아요", "미리 놓인 코드를 고쳐 두 맵을 지나가요.", 힌트1(start) "처음 코드를 실행하면 어느 맵에서 실패하는지 보세요.", 힌트2 "if는 언제 검사할까요? 벽이 나타나는 순간에도 검사하려면 if가 어디에 있어야 할까요?"
- en: "if Doesn't Keep Watching", "Fix the code that's already there to get through both maps.", "Run the starting code and see which map fails.", "When does if check? Where should if be so it also checks when the wall appears?"

## 조건 예측 도전 (T17 형식 확장)
- id `p-u2-1`, stageId `u2-1`(그 스테이지를 깨야 열림), 맵 `S.#`, `#.G`(변형 없음, 하나), 고정 코드 `if 막힘 [R], F, F`.
- 후보(엔진으로 계산, 변형 프로그램): 정답 = 그대로 실행(앞으로 한 칸 뒤 부딪혀 멈춤), 오해 "계속 지켜본다" = `F, R, F`, 오해 "막힘/열림을 거꾸로" = `R, F, F`. 세 결과의 위치·방향이 서로 달라야 함(테스트).
- 위치와 함께 **검사 결과(참/거짓)**도 보여 주기: 결과 화면에 "처음 검사: 앞이 열려 있었어요 → 안쪽을 건너뛰었어요" 같은 설명(ko/en, 문구는 Codex가 짧게 쓰되 정답을 미리 말하지 않게; Claude 검토).
- 목록의 u2-1 카드 아래에 기존 '예측 도전' 버튼 방식 그대로.
