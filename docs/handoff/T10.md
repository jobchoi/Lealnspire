# 작업 지시서 T10 — 가로 정사각형 블록, 블록 10개 상한, 넓은 작업 공간

- 지시: Claude Code · 구현: Codex(GPT) · 검증: Claude Code(사용자 시나리오 E2E)
- 작업 브랜치: `feature/T10-horizontal-blocks` (브랜치 변경·커밋·push 금지)
- 먼저 읽을 것: `AGENTS.md`, `CLAUDE.md`, `docs/GAME_DESIGN.md`(4절, 저학년 UX 원칙), `docs/TASKS.md`의 T10, `src/components/Editor.tsx`, `src/pages/PlayPage.tsx`, `src/engine/program.ts`, `src/index.css`

## 배경(사용자 피드백)

1. 블록이 아래로 길게 쌓이는 가로로 긴 카드 디자인 대신, **정사각형 블록이 옆으로** 이어지게. 무한히 늘지 않게 **최대 10개**. 모바일·작은 화면에 맞춰 나중에 바뀔 수 있음을 염두.
2. 반복 블록을 쓰면 작업 공간이 너무 작아 스크롤해서 봐야 한다.

## 요구사항(완료 조건)

1. **블록 상한 10개**: `src/engine/program.ts`에 `MAX_PROGRAM_BLOCKS = 10`(반복 블록과 몸체 블록 모두 1개로 셈, `countBlocks` 기준). 편집기의 실제 제한 = `min(stage.maxBlocks ?? 10, 10)`. 상한에서 팔레트 비활성화 + 안내. 엔진 테스트와 "모든 스테이지 정답 ≤ 10" 테스트 추가. `docs/GAME_DESIGN.md` 4절에 규칙 기록.
2. **정사각형 타일**: 작업 공간의 각 블록은 정사각형 타일(데스크톱 약 72~80px, 375px에서 약 56~64px, 최소 48px). 타일 안에는 큰 기호와 순서 번호(작게)만. 타일은 왼쪽 → 오른쪽으로 이어지고 줄이 차면 다음 줄로 감김(flex-wrap). 블록 사이에 진행 방향을 보여 주는 작은 `›` 같은 구분 표시 권장.
3. **반복 블록 표현**: 반복은 주황 테두리 틀(frame) 안에 `🔁 ×N` 머리 타일 + 몸체 타일들이 가로로 들어가는 형태. 틀 자체도 줄바꿈 가능. 선택(추가 대상)되면 틀이 굵게 강조되고 `⤵` 표시. 빈 반복은 틀 안에 "여기에 넣기" 자리(점선 정사각형).
4. **편집 방식(타일을 깨끗하게 유지)**: 타일마다 버튼을 붙이지 않습니다. 타일을 누르면 그 블록이 선택되고, 작업 공간 위(또는 아래) 고정 위치의 **작업 막대**에 `◀`(앞으로 옮기기) `▶`(뒤로 옮기기) `✕`(삭제), 반복이면 `−` `+` `⤵ 안에 넣기/해제`가 나타남. 다시 누르거나 빈 곳을 누르면 선택 해제. 기존 `moveBlock(up/down)`을 앞/뒤 의미로 재사용. 선택 블록이 삭제되면 선택 해제.
5. **넓은 작업 공간**: 블록 10개(반복 틀 포함 최악의 경우)가 1280x720 이상에서 **작업 공간 스크롤 없이** 모두 보임. 375x700에서도 맵·팔레트·실행 버튼이 보이는 상태로 10개가 작업 공간 안에 보이거나, 넘치면 작업 공간 내부 스크롤만(페이지 스크롤 없음). 맵 크기를 줄여 공간을 확보해도 됨(맵 칸 최소 40px).
6. **남은 칸 표시(글 없이 이해)**: "블록 n / 10" 글 옆에 10칸짜리 점(●○) 막대.
7. 현재 실행 블록 강조, 실행 중 편집 잠금, `initialProgram`(스테이지 4) 표시는 유지.
8. **나중에 레이아웃을 바꾸기 쉽게**: 타일 작업 공간을 별도 컴포넌트(예: `src/components/BlockTiles.tsx`)와 CSS 묶음으로 분리하고, 크기는 CSS 변수(`--tile-size` 등)로. `docs/ARCHITECTURE.md`에 "작업 공간 레이아웃은 교체 가능한 컴포넌트" 기록.
9. 접근성: 타일은 `<button>`(aria-label 예: "3번 앞으로", 반복은 "2번 반복 3번", 선택 시 `aria-pressed`), 작업 막대 버튼도 한국어 aria-label. 키보드 Tab으로 타일 선택과 작업 막대 조작 가능.
10. 테스트: 상한, 앞/뒤 이동, 선택 해제, 타일 렌더링(aria-label, 반복 틀, 빈 반복 자리) 단위·렌더링 테스트. 의존성 추가 금지. `npm run verify` 통과.
