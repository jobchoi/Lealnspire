# T84-5 지시서 — 관리자(교사·보호자) 대시보드 (구현 Codex, 기획 GPT, 문구·E2E·QC Claude)

브랜치 `feature/T84-admin-dashboard`(develop 최신). 먼저 docs/design/learning-history.md(**1-1절: 관리자 화면 잠금 없음(개발 중)**, 2절 GPT 원문 4절 관리자 화면안), src/model/historySummary.ts, src/view/pages/LearningPage.tsx(T84-4 구조·테마 방식), CLAUDE.md를 읽는다. [제안·잠정].

## 구현
1. 진입: 홈의 정보 영역(기존 "내 기록 안내" 근처)에 작은 버튼 **"교사·보호자"**. 게임 화면·결과 창에는 진입 버튼 없음. 잠금은 없고 화면 맨 위에 "개발 중: 잠금 없이 열려 있어요(서버 단계에서 계정으로 바뀜)" 표시. 새 페이지 `src/view/pages/AdminPage.tsx`.
2. 영역(로컬 단계: 이 브라우저의 학습자 1명):
   - **요약**: 정규 45개 중 완료 수, 최근 활동일, 기록 범위(상세 기록 시작일·보존 90일·정리된 기간이 있으면 표시), 저장 상태(저장 불가면 표시)
   - **단원별 진행**: 12단원 표 — 완료/전체, 진행 중 퍼즐, 활동 추정 시간(분 단위, "추정" 표기)
   - **살펴볼 퍼즐**: 최근 종료 실행 3회 연속 실패, 같은 실패 종류 반복, 도움 뒤 미완료 — 실패 종류를 아이 말이 아닌 어른용 설명으로(예: "벽에 부딪힘", "별에 도착하지 못함", "단계 상한(무한 반복 의심)", "반환값 없음" …). 능력 판정 문장 금지.
   - **도움 사용**: 힌트 1·2단계를 본 시도 수 / 전체 시도 수, 시범 이용(열기·끝까지), 도움 뒤 성공 여부, 이후 도움 없이 성공한 기록. 표본이 3시도 미만이면 "판단하기에 기록이 적어요".
   - **퍼즐 상세**: 퍼즐 선택 시 방문 → 실행 → 실패 → 힌트/수정 → 재실행의 시간순 목록(최근 상세 범위만, 요약된 기간은 "요약됨" 한 줄)
   - "기록 시작 전 진행" 사용자 안내
3. 어른용 화면이라 표·작은 글자 허용(본문 14px 이상), 그래도 버튼 44px·대비 4.5:1·키보드·제목 구조·표 머리글(`th scope`). 세 월드 테마는 쓰지 않고 차분한 기본 화면 + 홈으로 버튼.
4. 문구는 Codex가 ko/en 초안 → Claude가 검토·수정(아이용 문구 규칙 아님, 어른용 존댓말 "~습니다/~요" 중 하나로 통일 — 해요체 권장).
5. 단위 테스트: 집계 → 표(빈 상태, 기록 전 사용자, 3연속 실패, 표본 부족, 요약된 기간, 저장 불가), 퍼즐 상세 순서, ko/en.
