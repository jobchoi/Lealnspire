## 요구사항(완료 조건 = TASKS.md T5)

1. `src/storage/progress.ts`에서만 localStorage 접근(다른 파일에서 `localStorage` 직접 사용 금지). 키 예: `lealnspire.progress`. 저장 구조에 `version: 1`.
2. 저장 내용: 스테이지별 `{ completed: boolean, bestStars: 0~3, lastProgram: Program }`. 최고 별은 낮아지지 않음.
3. 잠금 해제 규칙(순수 함수): 스테이지 1은 항상 열림, N번은 N-1번 완료 시 열림. `isUnlocked(progress, stageIndex)` 같은 함수와 테스트. (목록 화면은 T6이 사용)
4. 불러오기 검증: JSON 파싱 실패, 다른 `version`, 구조가 맞지 않는 값(잘못된 블록 타입, 범위 밖 반복 횟수, 별 범위 밖 등)은 안전하게 빈 진행 상황으로 초기화(또는 해당 스테이지 항목만 버림). 테스트.
5. localStorage를 쓸 수 없을 때(접근이나 `setItem`이 예외) 게임은 메모리 상태로 계속 동작. 테스트(가짜 storage 주입 가능한 구조 권장, 예: `createProgressStore(storage?)`).
6. App 연결: 스테이지를 열 때 저장된 `lastProgram`(없으면 `initialProgram`, 없으면 빈 프로그램)으로 시작. 편집할 때마다 `lastProgram` 저장(과도하면 간단한 디바운스 가능). 실행 결과가 성공이면 `completed`와 `bestStars` 갱신.
7. 테스트는 Node 환경에서 가짜 storage로. DOM 테스트 라이브러리·의존성 추가 금지.
8. `docs/ARCHITECTURE.md`(폴더 구조, 저장 구조와 버전) 갱신. `npm run verify` 통과.
