## 문제
1. **도움 사용 표에 기록 없는 퍼즐 46개가 모두 나옴** — 각 행에 "판단하기에 기록이 적어요"와 0/0이 반복돼 실제로 본 퍼즐(1번)을 찾기 어렵다. → **시도나 도움 기록이 있는 퍼즐만** 행으로. 하나도 없으면 "아직 기록된 시도가 없어요." 한 줄.
2. **좁은 화면(≤700px)에서 7열 표가 글자 단위로 줄바꿈** → 좁은 화면은 퍼즐마다 카드(퍼즐 이름 + "시도 3 · 힌트1 0/3 · 힌트2 0/3 · 시범 0/0 …" 같은 정의 목록 `dl`)로. 넓은 화면은 표 유지. 단원별 진행 표도 같은 방식 검토.
3. **퍼즐 상세가 기록용 이벤트를 그대로 나열** — "활동 시간 구간을 기록했어요", "실행 결과를 계산했어요"+"결과까지 재생했어요"가 따로, 코드 수정 이벤트가 연속으로 반복. → 어른이 읽는 흐름으로 묶기: 방문 / 실행 → 결과(성공·실패 종류, 중단) 한 줄 / 코드 수정 n회(연속 묶음) / 고치기 / 되돌리기 / 힌트 n단계 / 시범 열기·끝까지·중간에 닫음 / 완료 / 방문 종료. `timeSegment`는 목록에서 빼고(시간은 단원 표에 이미 있음).
4. **시각 표기 반복** — 줄마다 "2026. 11. 28. 오후 5:33:51". → 날짜별로 묶고 줄에는 시:분만.
