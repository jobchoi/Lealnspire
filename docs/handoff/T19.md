# T19 지시서 — 편집 한 번 되돌리기 (구현 Codex, QC Claude)

같은 작업 트리(`feature/T14-t13-polish`). 먼저 docs/PROJECT_MAP.md, CLAUDE.md, docs/ROADMAP.md, docs/TASKS.md의 T19를 읽는다. [제안·잠정] 작업.

## 목적
실수로 블록(특히 몸체가 든 반복)을 지웠을 때 바로 되돌릴 수 있게 해, 아이가 겁내지 않고 직접 고쳐 보게 한다.

## 할 일
1. Controller: 직전 편집 1회(추가·삭제·이동·반복 횟수 변경·반복 안에 넣기 등 프로그램이 바뀌는 모든 편집)를 되돌린다. 되돌리기 후 다시 되돌리기는 없음(redo 없음, 기록 1개). 선택·추가 대상 상태는 되돌린 프로그램에서 유효하게 정리(없는 ID면 해제). 되돌린 프로그램도 저장소에 저장.
2. 스테이지 이동, "고치기"(T15)·초기화와 무관하게 스테이지를 바꾸면 기록 삭제. 재생 중(잠금)에는 비활성. 재생이 끝난 상태에서 되돌리면 T22처럼 재생을 처음으로 되돌린 뒤 적용.
3. View: 작업 공간 근처(팔레트 줄 또는 작업 막대 옆)에 되돌리기 버튼, 세 월드 공통 기호(왼쪽으로 휘어 돌아가는 화살표, "처음으로"의 원형 화살표와 구분되게), aria-label "되돌리기", 44px+, 기록이 없으면 비활성. 문구 ko.json/en.json.
4. 단위 테스트: 반복 삭제 → 되돌리기 시 몸체·ID·블록 수 복원, 기록 1개 한계, 스테이지 이동 시 기록 없음, 잠금 중 거부.
5. 배치 기준(세 월드 × 1280×720·375×667·360×560, 스크롤 없음, 겹침 없음, 44px, 글자 잘림 없음) 유지.

## 하지 말 것
redo·여러 단계 이력, 게임 규칙·저장 형식 변경, e2e·package 수정, 새 의존성, 커밋·push, TASKS/NEXT_SESSION/WORK_HISTORY 수정.

## 검증
`npm run verify`. 포트 불가 시 E2E·브라우저는 미검증. Claude가 e2e(반복 삭제 → 되돌리기 → 실행 성공)를 추가한다.
