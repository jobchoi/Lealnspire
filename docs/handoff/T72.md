## 구현
1. **기록 삭제 실패 안내**(높음): 지금은 메모리 기록을 먼저 비운 뒤 저장소 삭제를 시도하고, 실패해도 "저장하지 않고 있어요"만 보임(ProgressRepository.ts:127, HomePage.tsx:25). 삭제 결과(성공/실패)를 돌려주고, 실패하면 ko "기록을 지우지 못했어요. 이 기기에 기록이 남아 있을 수 있어요. 다시 시도하거나 브라우저 설정에서 이 사이트의 저장 데이터를 지워 주세요." / en "Couldn't delete the progress. It may still be saved on this device. Try again, or clear this site's data in your browser settings." + "다시 시도"/"Try again" 버튼. 실패 시 메모리만 비워 '지워진 것처럼' 보이지 않게. 단위 테스트(저장소 removeItem이 던지는 경우).
2. **단원 완주 → 다음 단원 안내**(중간): 단원 마지막 정규 퍼즐 성공 결과 창에 다음 단원이 열렸음을 알리고 "다음 단원으로" 버튼(다음 단원 첫 스테이지로). ko "{unit}이 열렸어요." / en "{unit} is now open." ({unit}은 기존 unitN 묶음 이름). 1단원은 보너스 안내와 2단원 안내를 함께(보너스는 선택 활동임을 유지). 12단원(마지막)은 기존 완주 문구만. 버튼 44px, 키보드 포커스.
3. **고치기 퍼즐 목표 문구 통일**(중간): initialProgram(또는 initialFunctions)이 있는 정규 스테이지의 목표가 모두 "미리 놓인 코드를 고쳐…"(en "Fix the code that's already there…")로 시작하게. 지금 어긋난 것: 1단원 4번 "명령 하나를 고쳐 도착해요." → "미리 놓인 코드에서 명령 하나를 고쳐 도착해요."(en "Fix one command in the code that's already there and reach the star."), 10단원 2번, 11단원 2번(각 문구는 기존 뜻을 살려 앞부분만 맞춤). 고치기 스테이지 목표 문구를 검사하는 단위 테스트 추가.
4. **문구 오류 수정**(ko/en 모두):
   - 1단원 4번 힌트2: "첫 칸에서 돌 때" → ko "한 칸 간 다음 돌 때, 로봇 입장에서 별은 오른쪽일까요 왼쪽일까요?" / en "After moving one cell, when the robot turns, is the star on its right or its left?"
   - 이벤트 미연결 신호: "연결된 처리기가 없어요. 아무 일도 없어요." → ko "실행할 처리기가 없어요." / en "No handler to run." (◇·○는 처리기가 없어도 문을 엶 — 문 상태 표시는 그대로)
   - "상자 A 1 바꾸기" → "상자 A의 값을 1만큼 바꾸기" (en은 "Change box A by 1" 유지)
   - "두 맵 모두 도착해 보세요" → "두 맵에서 모두 도착해 보세요"
   - en 다듬기: "Add: main end" → "Adding to: end of main", "Repeat the value passed in" → "Repeat ◆ times", "Not run this call" → "Skipped this call", "We did not look from here on" → "Not checked from here on"(같은 키를 쓰는 곳 모두)
5. **홈 전체 완주 표시**(낮음): 전체 과정 완주 상태면 홈에 작은 완주 배지(월드 기호 + "모든 단원을 완주했어요"/"All units complete"), 이어하기가 사라진 이유가 보이게. 44px·대비.
