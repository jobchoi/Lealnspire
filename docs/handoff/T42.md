## 의미 (Claude 확정)
- 블록 `{ type: 'while', condition: 'clearAhead', body }`. 센서 **앞이 열려 있음**(`clearAhead` = blockedAhead의 반대). 기존 `blockedAhead`와 같은 판정 함수 재사용.
- 실행: 도달하면 검사 → 참이면 body 실행 → **다시 검사** → … 거짓이면 다음 블록으로. 처음부터 거짓이면 body를 한 번도 실행하지 않음. 검사마다 check 프레임 1개, 단계 1로 셈(상한 1000). 회차 표시(T18)는 while에서 "N번째"(전체 수 없음, 예: `3`)로.
- 끝나지 않으면 단계 상한(stepLimit) — while이 원인이면 결과 문구를 "반복이 끝나지 않아요. while 안에서 조건이 바뀌는지 보세요."(en "The loop never ends. Check whether anything inside while changes the condition.")로, 실패 지점은 그 while 블록.
- 저장 v2 검증에 while 허용(condition 허용 목록 `clearAhead`), 편집 도우미(자식 목록 블록에 while 포함), countBlocks.
- 스테이지별 팔레트: `Stage.palette?: BlockType[]`(없으면 단원 기본). 3단원 스테이지는 **if를 빼서**(아래 지정) while이 필요하게 한다.

## 테스트 (단위)
while: 처음부터 거짓(0회), 매회 재검사, 빈 몸체(조건 불변 → stepLimit), 무한 반복 stepLimit과 원인 블록, 중첩(repeat 안 while, while 안 if — if는 2단원 블록이지만 Model은 허용), 회차. 세 스테이지 정답 성공·**지름길 없음**(각 스테이지 팔레트로 만들 수 있는 while 없는 프로그램 ≤ maxBlocks가 모든 변형을 동시에 못 풂 — T39 상태 변환 합성 방식), u3-3 처음 코드 stepLimit. 1단원·2단원 결과 회귀.
