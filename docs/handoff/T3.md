## 목적

플레이어가 블록을 클릭으로 조합해 프로그램(`Program`)을 만들 수 있게 합니다. 실행·재생은 T4이므로 **만들지 않습니다.**

## 요구사항(완료 조건 = TASKS.md T3)

1. 팔레트: 앞으로 / 왼쪽으로 돌기 / 오른쪽으로 돌기 / N번 반복(기본 3) 버튼. 클릭하면 **선택한 위치**에 추가: 아무것도 선택하지 않았으면 최상위 끝, 반복 블록을 선택했으면 그 반복 몸체 끝.
2. 작업 공간: 블록 목록(반복 몸체는 들여쓰기로 중첩 표시, 줄 번호 또는 순서 표시). 블록마다 삭제, 위로, 아래로 버튼. 반복 블록에는 횟수 변경(2~10, 범위 밖 불가). 반복 블록 클릭(또는 선택 버튼)으로 추가 대상 선택/해제, 선택 상태가 눈에 보일 것.
3. 블록 수 / 제한 표시(`maxBlocks` 없으면 블록 수만). 제한에 도달하면 팔레트 버튼 비활성화와 안내 문구.
4. 편집은 반드시 `src/engine/program.ts`의 `addBlock`, `deleteBlock`, `moveBlock`, `setRepeatCount`, `countBlocks`를 사용(편집 로직 중복 금지). 필요한 순수 보조 함수(예: 블록 id 생성, 경로 계산)는 `src/engine/`에 두고 테스트.
5. 블록 id는 프로그램 안에서 유일해야 함(T4의 실행 중 블록 강조에 쓰임).
6. 선택한 반복 블록이 삭제되면 선택이 풀려야 함.
7. 화면 문구는 `src/i18n/ko.ts`로 모읍니다(새 파일). 블록 이름도 여기에서.
8. `App.tsx`: 현재 스테이지(우선 `stages[0]`, 스테이지 선택은 T6)의 맵 옆(좁은 화면에서는 아래)에 편집기 배치. 스테이지에 `initialProgram`이 있으면 그것으로 시작. 편집 상태는 App(또는 편집기 컴포넌트)의 React state. T4에서 실행 버튼을 붙일 수 있게 `program`과 `onChange`를 props로 받는 구조 권장.
9. 접근성: 모든 버튼은 `<button>`이고 아이콘만 있으면 `aria-label`. 키보드로 조작 가능.
10. 폭 375px에서 가로 스크롤 없음(CSS).
11. 테스트: 새 순수 함수 단위 테스트, 편집기 컴포넌트는 `renderToString`으로 렌더링 확인(중첩 반복, 제한 표시, 비활성화 상태). DOM 테스트 라이브러리는 추가하지 않음.
12. `docs/ARCHITECTURE.md` 2절(현재 폴더 구조) 갱신. `npm run verify` 통과.
