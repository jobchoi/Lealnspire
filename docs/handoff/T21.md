# T21 지시서 — 반복 전략 전이 보너스 2개 (구현 Codex, 설계 기준·QC Claude)

같은 작업 트리(`feature/T14-t13-polish`). 먼저 docs/PROJECT_MAP.md, CLAUDE.md, docs/ROADMAP.md(라운드 1·2), docs/TASKS.md의 T21을 읽는다. [제안·잠정] 작업.

## 목적
8개를 끝낸 뒤, 배운 반복 전략을 **처음 보는 맵**에 옮겨 쓰는 선택 보너스 2개. 답이 기존 스테이지와 같은 모양이면 안 된다.

## 설계 기준 (Claude)
- B1(id 'b1', world 'train', 제목 "보너스 1: 큰 계단"): 반복 몸체에 같은 명령이 2번 이상 연속하는 패턴(예: 두 칸 오르고 꺾기). 기존 6번(3[F L F R])·7번(3[F F R])과 몸체가 달라야 한다.
- B2(id 'b2', world 'handheld', 제목 "보너스 2: 앞뒤가 있는 길"): 반복 앞 또는 뒤에 반복 밖 명령이 필요하고, 몸체에 서로 다른 명령이 3종 모두(앞, 왼쪽, 오른쪽) 들어가는 패턴. 8번(2[F L F R] F)과 답이 달라야 한다.
- 각각 maxBlocks와 starBlocks를 정하고, **지름길 검사 테스트**: maxBlocks 이하 블록 수의 반복 없는 프로그램(앞·왼·오 조합 전수)은 하나도 성공하지 않는다(반복을 써야만 풀림). 기존 stages.test.ts의 전수 탐색 방식을 참고하되 1초 안에 끝나게.
- 정답 2개 이상(기존 블록만)으로 성공하는지, 맵에 도달 불가 칸·의미 없는 벽이 많지 않은지(맵 크기 최대 6×6).
- 힌트 2단계(T16 형식, 정답 순서를 말하지 않는 문구)를 직접 작성하고 보고에 적을 것. Claude가 검토한다.

## 흐름
1. 정규 1~8은 그대로(8번 결과 창의 "모두 완주" 축하 문구·목록으로 가기 유지). 보너스는 스테이지 목록 맨 아래 "보너스" 묶음으로, 8번 완료 후 열림(B2는 B1 완료 후). 홈 "이어하기"는 정규 8개가 끝나기 전에는 보너스로 안내하지 않음.
2. 보너스 화면의 "다음 스테이지"는 B1→B2만, B2 성공 시 목록으로.
3. 저장: 기존 progress 형식(버전 1, stages 키)에 'b1','b2'를 추가하는 방식으로 버전 변경 없이 가능한지 확인하고, 이전 기록(1~8만 있음) 읽기·이어하기가 그대로인지 테스트. 버전 변경이 꼭 필요하면 이전 버전 읽기를 포함.
4. 예측 도전·힌트·실패 고치기·되돌리기 등 기존 기능이 보너스에서도 동작.
