# T38 지시서 — `if` 화면·여러 맵 실행·첫 퍼즐 U2-1 (구현 Codex, 내용·E2E·QC Claude)

브랜치 `feature/T33-unit2-plan`. 먼저 docs/design/unit2-conditions.md(특히 2·3·6·7절), docs/PROJECT_MAP.md, CLAUDE.md, docs/ROADMAP.md 라운드 3(개념어 방침), src/i18n/glossary.json을 읽는다. [제안·잠정]. Model은 T37에서 끝났다(run/runAll/if/check 프레임).

## 할 일
1. **팔레트에 `if` 블록**: 2단원 스테이지에서만 보임(1단원 팔레트·배치 불변). 타일·버튼 표기는 개념어 방침대로 기호(갈림길 SVG) + `if` + 센서 그림(앞 막힘: 로봇 앞 칸의 벽 SVG). 보이는 글자는 `if`만, aria-label은 UI 언어 설명("앞이 막혔으면" / "if the path ahead is blocked"). glossary에서 키워드를 가져올 것(하드코딩 검사 통과). 세 월드 모두 표현.
2. **편집**: if 블록에 "안에 넣기"(repeat과 같은 방식, 기존 aria 계약 "…안에 넣기/…넣기 해제" 재사용), if 안 repeat·repeat 안 if, 되돌리기·고치기·삭제·이동이 if body에도 동작. 빈 if는 "여기에 넣기".
3. **검사 프레임 표시**: 재생·한 단계에서 check 프레임이면 로봇 앞 칸에 센서 표시(테두리+무늬, 색만으로 구분하지 않음), 결과 기호 ✓/✕ SVG와 짧은 문구("앞이 막혔어요" / "앞이 열려 있어요", 영어 "The path ahead is blocked" / "The path ahead is clear")를 role=status로. 참이면 if body 블록들이 강조되며 실행, 거짓이면 if 타일에 "건너뜀" 표시(흐린 body + 기호). 맵 aria 설명에 센서 결과 포함.
4. **여러 맵(variants) 실행**: 2단원 스테이지는 GameController가 runAll 사용. 맵 위에 맵 카드 `1/2`, `2/2`와 각 결과(✓/!) 표시, 실행하면 변형을 차례로 재생(한 맵 끝나면 짧은 전환 후 다음 맵). 실행 전에도 모든 변형을 작게 미리 보기(맵 카드 눌러 전환 가능, 44px). 결과 창: 모두 성공이면 성공(2단원은 통과 중심: 별 3개 고정), 실패면 "2번 맵에서 벽에 부딪혔어요"처럼 변형 번호 포함. "고치기"는 실패한 변형으로 전환 후 원인 블록 선택·포커스(T15·T28 재사용). 회차 표시(T18)·되돌리기(T19)·결과 후 바로 편집(T22) 유지.
5. **스테이지 U2-1**(id `u2-1`, world `sketchbook`, 잠정): 명세 4절 U2-1 두 맵 그대로, startDir E, maxBlocks 6, solution `repeat 4 [ if 막힘 [R], F ]`. 제목·목표·힌트(아래 문구 그대로 ko/en에), 힌트 1단계 강조 `walls`.
   - ko: 제목 "막히면 돌아요", 목표 "두 맵을 같은 코드로 지나가요.", 힌트1 "두 맵에서 모퉁이가 어디에 있는지 비교해 보세요.", 힌트2 "모퉁이 위치가 다른데, 로봇은 언제 돌아야 하는지 어떻게 알 수 있을까요?"
   - en: title "Turn When Blocked", goal "Get through both maps with the same code.", hint1 "Compare where the corner is on each map.", hint2 "The corners are in different places. How can the robot know when to turn?"
6. **단원 흐름**: 스테이지 목록에 "2단원: 조건 (if)" 묶음(영어 "Unit 2: Conditions (if)"), 정규 1~8을 끝내면 열림(보너스는 필요 없음). 1단원 완주 문구·보너스 흐름 불변. 홈 "이어하기"는 1단원 정규를 끝냈고 2단원을 안 끝냈으면 U2-1로.
7. 문구는 ko.json·en.json 둘 다(키·치환 인자 일치 검사 통과). 저장은 v2 그대로(if는 T37에서 검증 허용됨).
8. 배치: 2단원 화면(맵 카드 + 센서 표시 포함)도 세 화면 크기에서 맵·팔레트·실행 버튼이 스크롤 없이 보임, 44px, 글자 잘림 없음.
