## 구현
1. **편집 뒤에도 시범 버튼**: `canOfferDemo`에서 `edited` 조건을 빼되, 편집했거나 이미 본 시범이면 강조(`demo-suggested`) 없이 작은 버튼으로 둔다. 실행 중·결과 창에서는 지금처럼 숨김. 저장된 코드가 있는 재방문도 같다. 시범을 열고 닫아도 실제 코드·선택·삽입 대상·진행 불변(기존 테스트 확장).
2. **이전/다음 항상 제공**: 동작 줄이기가 아니어도 이전·다음 버튼을 보인다(멈추기/계속 보기는 자동 재생일 때만 추가). 이전/다음을 누르면 자동 재생은 멈춘 상태가 된다. 동작 줄이기면 지금처럼 자동 진행 없음.
3. **장면 대체 설명**: 장면(`.demo-scene`)은 계속 aria-hidden이되, 정보가 담긴 컷(`cue`가 있는 컷)은 낭독용 한 문장을 추가로 제공(시각적으로 숨긴 텍스트, 상태 문장 다음에 읽힘). 기호 나열(`◎8 · #2 ✓`)이 아니라 말로: 예 ko "목표는 8이에요. 번호 2에서 찾았고 번호 0과 1은 보지 않았어요." / en "The target is 8. It was found at index 2; indexes 0 and 1 were not checked." 대상: list, search, logic, parameter, variable, return, event, condition, else, while(그 밖은 상태 문장으로 충분하면 생략). 문구는 ko/en 모두 `demo.scenes.<id>.alt<컷>` 키로. Claude가 검토 후 고칠 수 있음.
4. **작은 보조 글자**: 시범 창 안 순번·회차 등 9~10px 글자를 12px 이상으로(배치가 깨지지 않게 블록 크기 조정 가능). 375·360에서 창 안 내용이 잘리지 않을 것.
