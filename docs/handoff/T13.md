# 작업 지시서 T13 — 테마 월드 3종(스케치북 · 기차 마을 · 게임기)

- 지시: Claude Code · 구현: Codex(GPT) · 검증: Claude Code(사용자 시나리오 E2E + 스크린샷 육안)
- 작업 브랜치: `feature/T13-theme-worlds` (브랜치 변경·커밋·push 금지)
- 먼저 읽을 것: `docs/PROJECT_MAP.md`, `CLAUDE.md`, `AGENTS.md`, `docs/TASKS.md`의 T13, `docs/design/concepts/`(**sketchbook.html, train.html, handheld.html — 이 시안의 모습을 실제 게임에 구현하는 것이 목표**), `src/view/`, `src/view/theme/defaultTheme.ts`, `e2e/helpers.ts`

## 목적(사용자 결정)

같은 게임 규칙을 세 가지 세계로 보여 줍니다. "같은 반복도 세계마다 다르게" 보여 새로운 자극을 줍니다. 지금 화면은 "윈도우 XP 시절 네모 버튼 같다"는 평가를 받았으므로, **시안 수준의 완성도**가 기준입니다.

- 월드 배치 [확정]: 스테이지 1~3 스케치북, 4~6 기차 마을, 7~8 게임기 (`stage.world`)
- 완주한 스테이지는 다른 월드로 다시 풀 수 있음

## 테마별 표현(시안을 따름)

| 요소 | 스케치북 `sketchbook` | 기차 마을 `train` | 게임기 `handheld` |
|---|---|---|---|
| 배경·틀 | 줄 공책, 스프링, 종이 질감, 마스킹 테이프·포스트잇(힌트) | 하늘·구름·잔디, 나무 간판 | 게임기 본체(베젤, LED), 도트 화면 |
| 맵 | 크레용 테두리 격자, 빗금 벽, 별 목표, 낙서 로봇(SVG `feTurbulence` 거친 선) | 이소메트릭 섬(벽=바위 블록, 목표=역·깃발, 로봇=꼬마 기차) | 녹색 도트 화면(벽=벽돌, 목표=도트 깃발, 로봇=8×8 도트), 주사선 |
| 팔레트 | 동그란 스티커(크레용 화살표) | "앞으로 칸" 등 차고 버튼 | 방향 패드(위=앞으로, 좌/우=돌기) + B 버튼=반복 |
| 작업 공간 | 줄 공책 위 그림 일기, 칸 사이 손그림 화살표 | 기차 칸이 선로 위에 연결, 앞에 기관차 | 10칸 카트리지 슬롯(빈 칸 표시) |
| 반복 표현 | 크레용 괄호 + "3번" 손글씨 | 노란 순환 선로 + "3바퀴" 배지 | 점선 테두리 칩 + `×3` |
| 실행 버튼 | 크레용 모양 "해 보기!" | 빨간 "출발!" | 빨간 원형 A 버튼 |
| 글꼴 | Gaegu, Gamja Flower | Do Hyeon, Black Han Sans | Press Start 2P(숫자·영문) + Do Hyeon(한글) |
| 실행 중 강조 | 흔들림 | 칸이 들썩임 | 깜빡임 |

- 아이콘·그림은 **모두 SVG**(이모지 금지: 이모지 글꼴 없는 기기에서 네모로 깨짐)
- 글꼴은 설치된 `@fontsource/*` 패키지를 import(외부 CDN 금지). 한글 하위 집합(`korean-400.css` 등)을 우선 사용
- `prefers-reduced-motion`이면 애니메이션 끔

## 구조 요구사항

1. `src/view/theme/`에 `sketchbook.ts`·`train.ts`·`handheld.ts`(+ 각 CSS, SVG 컴포넌트)로 `Theme` 구현. 필요하면 `Theme` 인터페이스를 넓힘(맵 렌더러, 팔레트 렌더러, 반복 틀, 실행 버튼, 배경 등). 게임 규칙·컨트롤러는 바꾸지 않음(View만).
2. 현재 스테이지의 `world`로 테마 선택. 완주한 스테이지에서는 다른 월드로 바꿔 보는 선택 UI(기호 3개: 공책·기차·게임기, aria-label 한국어). 진행 저장 구조 변경이 필요하면 `ProgressRepository` 버전을 올림.
3. 스테이지 목록 화면도 월드별로 묶어 보여 줌(월드 이름·그림). 첫 화면은 세 월드를 소개.
4. **E2E 계약 유지**: 접근성 이름(팔레트 `앞으로`/`왼쪽으로 돌기`/`오른쪽으로 돌기`/`N번 반복`, `실행`, `한 단계`, `처음으로`, `느리게`/`보통`/`빠르게`, 타일 `"<번호>번 ..."`, 작업 막대 `...삭제`/`...늘리기`/`...줄이기`/`...추가 대상으로 선택|...안에 넣기`/`...선택 해제|...넣기 해제`/`...앞으로 옮기기`), 클래스(`.palette`, `.workspace`, `.board`, `.run-button`, `.playback-controls`, `.editor`, `.block-active` 또는 `[aria-current=step]`), 역할(`[role=dialog]`, `[role=status]`). 테마마다 **보이는 글은 달라도 aria-label은 같음**.
5. **배치 기준 유지(모든 테마)**: 1280×720·375×667에서 블록 10개가 작업 공간 스크롤 없이 보임, 360×560에서 블록 두 줄 이상, 페이지 스크롤 없이 맵·팔레트·실행 버튼 보임, 버튼 44px 이상, 글자 잘림 없음. 게임기 본체 같은 장식이 작은 화면에서 공간을 먹지 않도록 축소.
6. 문구는 `src/i18n/locales/ko.json`(테마별 키 예: `themes.train.run`). 화면 코드에 한글 리터럴 금지(기존 테스트).
7. 단위·렌더링 테스트: 테마 선택 규칙(world → theme, 완주 후 교체), 각 테마의 렌더링(aria-label 동일, 반복 표현), 이소메트릭 좌표 변환 같은 순수 함수.
8. `docs/PROJECT_MAP.md`(새 파일·"테마 추가하려면" 행), `docs/ARCHITECTURE.md`, `docs/GAME_DESIGN.md`(월드 설명) 갱신. `npm run verify` 통과.
