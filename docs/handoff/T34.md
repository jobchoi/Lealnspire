# T34 지시서 — 개념어 방침·용어집·언어 키 검사 (구현 Codex, 방침·QC Claude)

브랜치: `feature/T33-unit2-plan`(v1.0.0 위). 먼저 docs/PROJECT_MAP.md, CLAUDE.md, docs/ROADMAP.md 라운드 3(개념어·언어 방침), docs/GAME_DESIGN.md 11절을 읽는다. [제안·잠정].

## 목적
"과한 한글화를 피하고 개념어는 영어 키워드 + 기호, 설명은 UI 언어"(사용자 결정 2026-11-25)를 코드에서 지킬 수 있는 단일 출처를 만든다. 이번 작업은 **기반**이다. 영어 번역 완성은 T35(Claude 번역).

## 할 일
1. `src/i18n/glossary.json`: 항목마다 `{ id, keyword, ko: { name, short }, en: { name, short }, avoid: { ko: [], en: [] } }`. 현재 쓰는 개념부터: forward, turnLeft, turnRight, repeat, block, cell, run, step, reset(처음으로 = 실행 상태 초기화, 코드 삭제 아님), fix, undo, hint, star, stage, world, bonus, predict. 앞으로 쓸 개념(if, else, while, function, set/variable, return, on/event, list, index, condition, parameter, argument)도 keyword와 짧은 정의만 미리 넣는다(화면에 아직 안 씀). keyword는 영어 소문자(예: repeat, if).
2. 반복 블록 타일 표기를 방침대로: 세 월드 모두 **`repeat ×N` 키워드 + 기호**를 기본으로 하되 월드 표현(스케치북 크레용, 기차 "N바퀴" 표지판, 게임기 ×N)은 키워드와 함께 보이게(예: 기차 표지판 위에 작게 `repeat`). 타일 aria-label은 한국어 설명 유지("N번 반복"). 팔레트의 반복 버튼 라벨은 `repeat` + 한국어 짧은 설명(예: "repeat · N번 반복"). 앞으로/돌기는 기호 중심 그대로(개념어가 일상어라 영어화하지 않음).
3. 검사 테스트(src/i18n): (a) 공식 지원 locale 목록(지금은 ko만, T35에서 en 추가)의 모든 leaf key와 `{치환}` 인자가 ko와 일치, (b) 개발용 부분 locale은 키가 ko의 부분집합, (c) glossary의 keyword가 화면에서 쓰일 때 glossary에서 가져오는지(하드코딩 금지 — 예: 'repeat' 문자열 리터럴이 view에 직접 있지 않음), (d) glossary 항목의 ko/en 이름·짧은 설명이 비어 있지 않음.
4. ARCHITECTURE.md에 개념어 방침과 glossary 사용법 짧게(문서 수정 허용: ARCHITECTURE.md, PROJECT_MAP.md만).
