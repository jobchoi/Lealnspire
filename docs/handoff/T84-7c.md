## 구현
1. 진입: 홈에 큰 버튼 **"공장 만들기"**(48px+, 그림+글자). 새 페이지 `src/view/pages/FactoryPage.tsx`. 1단원 완료 전에는 시작 상태 만들기·둘러보기만, 코드 제작 잠금 안내(개방은 `factoryAccess`).
2. 화면 구성(넓은 화면 2열, 좁은 화면 세로):
   - **공장 그림**: 입력 벨트(출구 화살표·앞 상자 강조, "앞 상자부터 나와요"), 더미 3개(잎·달·해 기호, 투명 통, 손잡이는 맨 위에만, "맨 위부터 꺼내요"), 집게(빈/상자). 상자 ◆○△ SVG(색만으로 구분 금지).
   - **시작 상태 탭**: 벨트·더미에 상자 추가·삭제·순서 바꾸기(버튼 방식, 44px), 용량 표시(벨트 n/12, 더미 n/6, 전체 n/18).
   - **코드 탭**: 팔레트(개방된 블록만, 잠긴 단원은 안내), 작업 공간(퍼즐 편집기 타일 스타일 재사용 가능), 블록 수 n/30.
   - **실행 막대**: 실행·한 단계·처음으로·속도. 실행 중 편집 잠금. 매 실행은 시작 상태에서.
   - **관찰**: 실행 블록 강조, 집거나 놓은 상자 강조, 마지막 동작 한 문장("벨트에서 ◆ 상자를 집었어요"), 시작 모습과 현재 모습 비교, 끝나면 "실행이 끝났어요"·"내가 생각한 모습인가요?". 정답 판정·점수 없음.
   - 오류는 3차 기획 4절 아이 말 문구(빈 벨트·빈 더미·집게 찼음·더미 가득·안전 상한)로, 원인 블록 강조.
3. 문구 ko/en은 Codex 초안 → Claude 검토(개념어 규칙: repeat·if·while·function 등 영어 키워드 유지, 설명은 해요체).
4. 세 월드 테마, 1280/375/360 가로 스크롤·겹침 없음, 버튼 44px, 대비 3:1, 이모지 금지, 키보드만으로 시작 상태·코드·실행, 화면 낭독(벨트·더미 상태를 "잎 더미: 아래부터 ○, ◆ — 맨 위 ◆"처럼), 동작 줄이기 정적 표시.
5. 단위 테스트(화면): 개방 전/후 팔레트, 시작 상태 편집 버튼, 실행·한 단계·처음으로, 오류 표시, ko/en. 7-나 GPT 참고: 중간 단원만 미완료인 개방 조합 테스트 추가.
