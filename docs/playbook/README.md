# AI와 개인 프로젝트 만들기: Lealnspire 플레이북

이 문서는 비전문 개발자와 교사가 Claude Code와 Codex를 함께 사용한 Lealnspire의 준비 과정과 시행착오를 따라가도록 만든 안내서입니다. 이 프로젝트의 기록을 사례로 삼으므로, 다른 프로젝트에는 경로와 규칙을 맞게 조정하세요.

## 목차와 사용법

1. [작업 전 준비물](01-prerequisites.md): 계정과 컴퓨터 환경을 점검합니다.
2. [두 AI의 협업](02-orchestration.md): 지시서부터 검증과 기록까지 한 작업씩 진행합니다.
3. [시행착오](03-lessons.md): 문제가 생기면 증상과 대응을 찾아봅니다.
4. [블로그 연재 구상](04-blog-outline.md): 경험을 설명할 글과 화면을 계획합니다.

처음에는 1번부터 읽고, 작업 중에는 2~3번을 참고하세요. 명령은 프로젝트 폴더에서 실행하며, 설치나 설정 변경 전에는 출력과 비용을 확인하세요. 근거는 저장소의 [작업 기록](../WORK_HISTORY.md), [작업 규칙](../../CLAUDE.md), [Codex 안내](../../AGENTS.md), [프로젝트 README](../../README.md), [T0b 지시서](../handoff/T0b.md), `scripts/`입니다.
