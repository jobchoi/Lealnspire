# 좌석/자원 선택 UX 패턴

좌석, 책상, 방, 장비처럼 공간이나 시간에 따라 선택 가능 여부가 달라지는 자원에 적용하는 일반 가이드다. 서비스별 정책·법규·접근성 기준을 대신하지 않는다.

## 원칙

- 사용자의 목적과 적용 시간·인원부터 정하고, 실제 공간 관계가 중요하면 배치도, 비교와 검색이 중요하면 목록/격자를 제공한다. 두 표현을 같은 데이터에 연결한다.
- 식별자와 표시 이름, 위치와 자원 자체, 현재 선택과 확정된 배정을 분리한다. 선택 수 제한과 기간을 선택 전에 보여 준다.
- 사용 가능 여부와 불가 사유를 텍스트·모양·접근 가능한 이름으로 함께 알린다. 색이나 위치만으로 의미를 전달하지 않는다.
- 확인 화면에서 자원·이용자·기간·비용 등 결정에 필요한 내용을 재확인하고 명시적으로 확정한다. 취소와 오류에서 사용자의 유효한 입력을 보존한다.
- 화면의 가용성은 순간 정보다. 서버의 원자적 검사와 저장이 최종 권위이며 선택 자체가 선점인지 명시한다.

## 상태 모델

| 상태 | 의미와 선택 가능성 |
| --- | --- |
| 빈/이용 가능 | 선택 기간과 정책에 대해 선택 가능 |
| 사용중 | 실제 사용 중인 상태. 제품의 시간 정책에 따라 다른 기간에는 선택 가능할 수 있음 |
| 예약됨 | 해당 기간에 확정된 예약 또는 배정이 있어 선택 불가 |
| 사용중지 | 관리자 정책이나 장애로 선택 불가. 사유 제공 |
| 선택됨 | 현재 사용자의 로컬 선택. 확정 또는 선점과 별개 |
| 임시 점유(선택 사항) | 서버가 만료 시각까지 확보한 상태. 만료와 해제 조건을 알려야 함 |

이 상태는 단일 열거형으로 무조건 합치지 않는다. 자원 운영 상태, 기간별 점유/예약, 사용자 선택, 필요 시 임시 점유는 서로 다른 축이다. 통로·장식·빈 셀은 자원이 아니며 선택 대상에서 제외한다. 로딩·오류·정보가 오래됨도 표시한다.

## 흐름

1. 공간·기간·인원과 선택 수를 정한다. 필요하면 구역과 조건을 필터링한다.
2. 기간 기준 상태가 표시된 배치도 또는 동등한 목록에서 선택한다. 단일 선택은 라디오 의미, 복수 선택은 체크박스 의미를 사용하고 제한을 안내한다.
3. 선택 요약과 조건을 확인한다. 취소하면 확정하지 않으며 선택 복원 여부를 명확히 한다.
4. 서버가 최신 상태·권한·시간 중복을 원자적으로 재검사해 확정한다. 성공 시 확정 내역을 보여 주고, 충돌 시 최신 상태와 사유를 알려 재선택하게 한다. 재시도는 중복 생성되지 않게 설계한다.
5. 변경·취소 정책과 이력을 제공한다. 연속 작업은 성공한 항목과 미처리 항목을 구분하고 중단 후 결과를 알린다.

## 체크리스트

- [ ] 공간·기간·시간대·종료 경계와 겹침 규칙이 명확한가? 시간대와 일광절약 시간 처리가 필요한가?
- [ ] 단일/복수 선택 한도, 선택과 확정 또는 임시 점유의 차이, 만료 시각이 명확한가?
- [ ] 충돌·장애·통신 중단·중복 제출 시 입력 보존과 복구 경로가 있는가?
- [ ] 키보드로 진입·이동·선택·확인·취소가 가능하고 포커스가 보이고 합리적으로 복귀하는가?
- [ ] 스크린리더에 자원 이름·상태·선택 여부·불가 사유와 결과가 전달되는가? 목록 대안이 있는가?
- [ ] 모바일 터치 영역, 확대·스크롤, 큰 글자와 가로 화면에서 정보와 확정 버튼을 사용할 수 있는가?
- [ ] 관리자가 배치·사용 중지·영향 확인을 수행하고 기존 배정과 이력을 보존할 수 있는가?
- [ ] 동시 사용자, 만료, 기간 경계, 접근성, 취소 및 재시도를 실제 흐름에서 검증했는가?

## 안티패턴

- 초록/빨강만으로 상태를 구분하거나 사용 불가 이유 없이 비활성화한다.
- 클릭 즉시 확정하면서 이를 알리지 않거나, 로컬 선택을 확정된 예약처럼 표시한다.
- 과거 조회 시 현재 배치와 현재 상태만 적용해 당시 상황을 잘못 표현한다.
- 최신 상태 검사를 브라우저에만 맡겨 동시 확정 시 중복을 허용한다.
- 충돌 시 다른 자원을 자동 배정하거나 입력 전체를 지운다.
- 배치도만 제공해 키보드·스크린리더·작은 화면에서 자원을 찾기 어렵게 한다.
- 일괄 처리의 부분 성공 여부와 복구 방법을 숨기거나 이력이 있는 자원을 무심코 삭제한다.
