# 블로그 연재 구상

실제 기록을 바탕으로 네 편을 구성합니다. 화면을 공개하기 전 계정 정보, 키, 토큰, 개인 경로가 보이지 않는지 확인합니다.

| 편 | 핵심 내용 | 스크린샷 아이디어 |
|---|---|---|
| 1. AI와 프로젝트 시작하기 | 교육용 웹 프로젝트의 목표, 작업을 작게 나누는 이유, 사람의 결정과 AI의 역할 | 프로젝트 소개와 작업 규칙의 역할 설명 부분 |
| 2. 새 PC 준비하기 | Git·Node·SSH, 점검 모드, MCP 승인과 비용 확인 | 개인 정보가 없는 점검 모드 결과와 MCP 연결 화면 |
| 3. 두 AI가 협업하는 한 사이클 | 지시서 → Codex 구현 → Claude QC → 수정 → 기록, T0b의 Node 점검 문제 | 지시서의 완료 조건과 수정 후 검증 결과 |
| 4. 실패를 다음 작업의 자산으로 | 403, 설정 파일 형식, 브라우저 설치, stdin 대기와 진행 현황 기록 | 민감 정보를 가린 오류와 `PROGRESS.md`의 예시 행 |

각 편에서 실제로 검증한 환경과 미검증 환경을 구분하고, 재현한 결과만 성공이라고 적습니다.
