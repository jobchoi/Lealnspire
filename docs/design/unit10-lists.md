# 10단원 리스트 — 여러 값을 순서대로 [초안·Claude, GPT 검증 전]

> Claude 초안(2026-11-26 23시). ROADMAP 라운드 3 리스트 행("첫 칸은 1", "길이 위치에도 원소가 있다" 오해, 번호 붙은 칸·포인터·길이 표시). GPT 독립 탐색으로 퍼즐·증명을 확인한 뒤 확정한다.

## 1. 배울 것

- 리스트는 값을 **순서대로** 담는다. 칸마다 번호(인덱스)가 있고 **0부터** 센다.
- `for each x in L [ … ]`는 앞에서부터 하나씩 꺼내 몸체를 실행한다(순회).
- 리스트 길이는 칸 수이고, 마지막 칸 번호는 길이 − 1이다.

## 2. 의미 (안)

- 맵마다 정해진 읽기 전용 리스트 `L`(정수 0~10, 길이 1~5). 학습자가 리스트를 만들거나 고치지는 않는다(첫 도입).
- 블록: `for each [L] [몸체]`(현재 원소를 ▣로 몸체에서 사용, 7단원 ◆와 같은 방식), `repeat ▣`, `repeat L[A]`(A번 칸 값), `repeat length(L)`.
- 범위 밖 인덱스(A ≥ 길이)는 실행 오류 `indexRange`(원인 블록 표시) — "길이 위치에도 원소가 있다" 오해를 드러냄.
- 화면: 번호 붙은 칸 줄 `[0:2][1:3][2:1]`, 현재 칸 포인터, 길이 표시.
- 팔레트: 앞·왼·오·repeat·set·change·리스트 블록. **if·while 없음**(센서로 맵을 읽는 우회 차단 — 5·8단원과 같은 증명 방식).

## 3. 퍼즐 후보 (GPT 검증 필요)

| 퍼즐 | 배울 것 | 아이디어 |
|---|---|---|
| u10-1 | 순회 | 맵마다 L이 다름(예 [2,3,1] / [1,1,4]), 정답 `for each [L] [repeat ▣ [F], L]`. 구간 길이에 규칙이 없어 상자 A 하나로는 못 풂 |
| u10-2 | 0부터 세기(고치기) | 미리 놓인 `set A ← 1, repeat L[A] [F] …`가 둘째 값을 씀 → A를 0으로 고침 |
| u10-3 | 길이 | `repeat length(L) [ … ]`로 맵마다 다른 개수의 같은 모양 반복. 범위 오류 예측 포함 |

## 4. 증명 계획

리스트 블록만 뺀 문법(F/L/R, repeat 숫자·A, set·change)에서는 맵이 실행에 영향을 주지 않으므로(시작 A가 같다면) 모든 맵에 같은 이동열 → 공통 이동열 전수 탐색으로 동시 성공 없음을 보인다(8단원 방식). 맵별 시작 A를 쓰면 A 하나로 정보가 한 개뿐이라 구간 셋을 표현할 수 없음을 탐색으로 확인.
