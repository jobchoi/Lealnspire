# 5단원 변수 [제안·잠정]

상자 A 하나에 정수 0~20을 담는다. set은 수학의 등식이 아니라 실행 순서에 따라 값을 넣는 동작이다. repeat A는 반복에 들어갈 때의 값을 고정한다. 반복 몸체에서 A를 바꿔도 진행 중인 반복 횟수는 바뀌지 않는다. 실행 값은 저장하지 않으며 변형마다 시작 값으로 초기화한다.

| 퍼즐 | 시작 값 | 제한 | 정답 |
|---|---|---|---|
| u5-1 | 2, 4 | 4 | repeat A [앞], 왼, 앞 |
| u5-2 | 1, 2 | 6 | repeat 3 [repeat A [앞], 왼, A+1] |
| u5-3 | 0 | 5 | set A ← 3, repeat A [앞], 왼, 앞 |

u5-1은 주어진 수를 횟수로 사용한다. u5-2는 각 구간이 한 칸씩 길어져 다음 반복에 쓸 값을 갱신한다. 도착하면 즉시 끝나므로 마지막 구간 뒤의 change는 실행되지 않는다. u5-3은 값이 자동으로 갱신된다는 오해와 실행 순서를 다루는 고치기 퍼즐이다. 맵이 하나이므로 개념 없는 우회 불가 증명 대상에서 제외한다.

u5-3의 지정 초기 코드에서 set은 최상위 두 번째 블록이다. 기존 편집기의 '앞으로 옮기기'는 반복 몸체를 건너뛰므로 한 번으로 맨 앞으로 이동한다(지시서의 두 번과 차이). 기존 이동 의미를 유지한다.

화면은 세 월드의 공통 상자 그림, 숫자, 프레임의 값 전후를 표시한다. 범위 오류 프레임은 마지막 유효 값을 유지하므로 범위를 벗어난 시도를 실제 값 변경으로 읽어 주지 않는다. 동작 줄이기에서는 전후 표시를 숨기고 현재 값만 표시한다. 맵 카드에는 해당 맵의 시작 값을 따로 표시한다.

전수 탐색은 `src/model/unit5.test.ts`에 있다. 모든 맵의 벽이 아닌 칸·네 방향을 상태로 잡고 목표와 충돌은 흡수 상태로 만든다. 변수 없는 문법은 앞·왼·오·숫자 repeat(2~10), change 없는 문법은 여기에 set(0~20)·repeat A를 더한다. 후자는 모든 A=0~20 상태를 포함하며 repeat 진입 시 횟수를 고정한다. 동일한 전체 상태 변환은 가장 적은 블록 수만 남긴다. 빈 몸체·연결·중첩도 포함하여 제한까지 검사한다. 상한 없이 실행하는 변환의 상위 집합에서 해가 없음을 확인하므로 실제 1000단계 제한에서도 해가 없다.

브라우저 검증은 현재 샌드박스의 로컬 포트 listen EPERM으로 실행 불가. Claude의 E2E·세 월드 × 세 화면 크기·44px·영어·동작 줄이기·스크린샷 육안 QC가 필요하다.

단위 검증 결과: 세 퍼즐의 정답은 각각 2/2·2/2·1/1 맵에서 성공했다. u5-3 초기 코드는 충돌한다. 전수 탐색은 u5-1 변수 없는 ≤4, u5-2 변수 없는 ≤6, u5-2 change 없는(set·repeat A 포함) ≤6에서 모두 동시 성공 코드가 없음을 확인했다. ko/en × 세 월드 렌더링, 값 변경·범위 실패 표시, 5단원 순차 개방·별 3개 저장·마지막 목록 복귀를 단위 테스트로 확인했다.
