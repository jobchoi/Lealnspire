# Claude 라운드 3 독립 초안 (GPT 결과 보기 전, 2026-11-25)
목표: 프로그래밍 기본 개념 전부를 "필요가 생기는 퍼즐"로 익히기. 글자 암기 대신 기호·상태 시각화.
단원 지도(각 단원 6~8스테이지 + 예측·고치기 재사용):
- 2단원 조건 if/else: 센서 "앞이 막혔으면"(앞 칸 빛남), 같은 코드로 두 맵 풀기
- 3단원 조건 반복 while/until: "별에 닿을 때까지 반복", 무한 반복 안전장치를 눈으로(단계 상한 표시)
- 4단원 함수 function: 동작 묶음에 이름(카드) 붙이고 부르기, 호출 스택을 카드 쌓기로 보여 줌
- 5단원 변수 variable: 상자(값 표시)에 열쇠·보석 개수 세기, 조건과 결합
- 6단원(이후) 자료구조 맛보기: 명령 대기열(queue)·되돌리기 스택(stack)을 게임 속 물건으로
개념어 방침: 블록·버튼의 개념어는 영어 키워드(repeat, if, else, while, function, variable) + 기호, 설명·힌트 문장은 한국어(또는 선택 언어). 영어 모드는 Claude가 직접 번역(유료 API 없음), 아이 눈높이 영어로.
순서: 개념어 표기 방침·영어 완성(T31) 먼저 → 2단원 엔진(조건) → 스테이지.
