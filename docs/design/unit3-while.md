# T42 — 3단원 조건 반복 while [제안·잠정]

센서는 현재 방향 바로 앞 한 칸을 검사한다. clearAhead는 기존 blockedAhead 판정의 반대이며, while 도달 시 검사 → 참이면 몸체 → 재검사를 반복한다. 처음부터 거짓이면 몸체는 0회 실행한다. 목표에 도착하면 기존처럼 즉시 성공한다.

검사는 check 프레임 한 개와 실행 단계 한 개를 만든다. 몸체 명령과 합쳐 1000단계를 넘지 않는다. 빈 몸체도 검사로 상한에 도달한다. while 실행 안에서 상한에 걸리면 가장 안쪽 원인 while ID를 RunResult.whileLimitBlockId에 기록하고, failurePoint와 고치기는 그 블록을 선택한다. 일반 반복의 기존 진입 상한도 유지한다.

Frame.loops의 count는 while에서 생략하며 iteration만 표시한다. 타일은 되감기·앞 열림 센서·glossary의 while 키워드·다시 검사 표시, 몸체는 초록 이중 둥근 테두리로 구분한다. 검사 상태는 열림→계속 / 막힘→멈춤으로 표시한다. 저장 v2는 clearAhead 조건과 body만 허용한다(else 금지). hasBody를 사용하는 편집·복제·개수 계산은 while도 포함한다.

맵·초기 코드·한영 문구는 handoff/T42.md의 지정값을 따른다. Stage.palette가 없으면 기존 단원 팔레트를 유지한다. u2-6 완료 뒤 u3-1부터 순차 개방하며 보너스 완료는 요구하지 않는다. 각 단원 마지막 성공은 목록으로 돌아가고 이어하기는 3단원까지 찾는다. 전체 변형 통과 시 별 3개이며 u3-3에 단원 완주 문구를 표시한다.

단위 검증은 0회·재검사·빈 몸체·무한 반복 원인·중첩·회차·편집·v2 저장·순차 개방을 포함한다. 지름길 증명은 현재 팔레트로 만들 수 있는 코드 기준이다. 스테이지 테스트는 팔레트에서 while을 제외한 모든 상한 이하 프로그램의 상태 변환을 합성하여 전체 변형 동시 성공이 없음을 검사한다. u3-3은 repeat도 제외한다. 1단원 프레임 fixture와 2단원 테스트는 유지한다.
