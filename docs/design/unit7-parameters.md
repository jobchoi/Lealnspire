# 7단원 매개변수 — 함수에 값 건네기 [제안·잠정]

> 기획: GPT 독립 기획안(2026-11-26, 읽기 전용, 원문 `~/project/_progress/logs/unit7-gpt-plan.md`) → Claude 검토·확정. 근거: ROADMAP 라운드 3 매개변수·지역 범위 행("매개변수를 바꾸면 원래 변수도 바뀐다" 오해, 호출마다 값 토큰), 사용자 결정(개념 중심, 글자 입력 없음).

## 1. 배울 것

- 같은 함수가 **부를 때마다 다른 값**을 받아 다르게 움직인다.
- 받은 값(◆)은 **그 호출에만** 있다(호출마다 새로 생기고 끝나면 사라짐). `★(A)`는 A의 값을 **복사**해 건네므로 바깥 상자 A는 바뀌지 않는다.
- 함수 안에서 A를 읽으면 건넨 값이 아니라 바깥 상자 A를 읽는다(7-3 고치기).

## 2. 의미 (Model)

- 함수 정의에 선택 입력 하나: `FunctionDef.param?: true`(입력 홈 ◆ 하나, 이름 없음).
- 호출 인자: `call.arg?: { kind: 'number'; value: 0~20 } | { kind: 'A' }`. 입력이 있는 함수는 인자 필수, 없는 함수는 인자 금지.
- 함수 몸체의 repeat 횟수 원천에 `◆` 추가(`countParam: true`). ◆는 입력이 있는 함수 몸체에서만 허용(main·입력 없는 함수에서 거부).
- 실행: 호출 순간 인자를 평가(A는 그 순간 값)해 호출별 지역 칸에 복사. 입력은 읽기 전용(지역 대입 없음). repeat는 기존처럼 진입 시 횟수 고정. 함수 몸체의 모든 호출 금지(재귀·상호 호출 없음) 유지.
- 프레임: `call`에 `arg?: number`(전달값)와 호출 순번 `serial`(같은 호출 블록이 여러 번 실행돼도 구분). 기존 A는 그대로 모든 프레임에.
- 블록 수: 정의·입력 홈·인자는 세지 않음(4단원과 같음).
- 저장: v2 유지(T47·T51과 같은 결정: 외피 불변, 블록 필드 검증 확장, 단원별 허용 여부로 거부 시 그 스테이지 코드만 비움). 7단원 스테이지는 `params: true`.

## 4. 화면

- 함수 카드 머리에 입력 홈 `◆`(켜기/끄기 — 켜면 이 함수는 값을 받음). 호출 타일 `★(2)`·`★(A)`: 선택하면 작업 막대에 값 −/+ 와 "A로" 바꾸기(5단원 repeat 원천 바꾸기와 같은 방식).
- 함수 안 repeat 원천 바꾸기: 숫자 → A → ◆ 순환(◆는 입력 있는 함수 안에서만).
- 실행 중: 호출 타일에 `A → 4`처럼 건넨 값, 함수 카드 입력 홈에 `◆4`, 상자 A는 그대로 `A=4`. 호출이 끝나면 입력 홈을 비움. 색만으로 구분하지 않음.
