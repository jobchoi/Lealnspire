## 퍼즐 (시작 E, 두 맵 같은 코드, 블록 수는 몸체·함수 몸체 합산, 별 통과 중심)

| 퍼즐 | 맵 ① / ② | 입력 | 팔레트 | 상한 | 정답(인정 풀이) |
|---|---|---|---|---:|---|
| u12-1 구부러진 길 | `S...`/`###.`/`#G..` · `S.##`/`#.##`/`#.##`/`#.##`/`G.##` | A=0 | F/L/R, repeat, if/else, while | 4 | `repeat 7 [if 앞 막힘 [R], F]` (또는 `repeat 3 [while 앞 열림 [F], R]`) |
| u12-2 다른 거리, 같은 동작 | `G...`/`###.`/`S...` · `G.....`/`#####.`/`S.....` | A=3 / A=5 | F/L/R, repeat 숫자·A, 함수·호출·매개변수 | 6 | `★(◆) = repeat ◆ [F], L`, main `★(A), ★(2), ★(A)` |
| u12-3 값일까, 개수일까? | `###G###`/`S......` · `#####G#`/`S......` | 리스트 [9,0,8] / [1,9,0,8,2], A=0 | F/L/R, repeat 숫자·A·리스트 원천, for each, if/else | 4 | `repeat length(L) [F], L, F` (또는 `for each [F], L, F`) |

- 첫 화면은 개념 이름을 알려 주지 않고 "같은 코드로 두 맵 모두 도착해 보세요". 힌트: "두 맵에서 무엇이 달라졌나요?" → "달라지는 정보를 어디에서 알 수 있나요?"
- **증명(GPT 독립 Python)**: u12-1 공통 이동열 전수(63상태) 동시 성공 0 — 반복+판단 필요. u12-2 매개변수 없이 ≤6(숫자·A 반복, 함수 두 개, 반복 안 호출 포함; 후보 변환 검사 547,757) 성공 0. u12-3 리스트 기능 없이 ≤4(if/else 포함) 성공 0. 범위는 각 퍼즐의 팔레트 — 전체 블록을 연 문법은 탐색하지 않음. if 자체·length 자체가 유일하다는 주장은 안 함(인정 풀이 둘).
- 허용 플래그: u12-1 기본, u12-2 `params`(repeat A 허용), u12-3 `lists`(repeat A 허용). 리스트와 매개변수·반환값을 같은 스테이지에서 함께 켜지 않음(반복 원천 편집 분기 충돌). 단원 표시·결과 문구는 기능 플래그가 아니라 12단원으로 연결해야 함. `u5-`·`u6-` 접두사에 묶인 허용 규칙은 이번 퍼즐에 필요 없음.
- 완주: 11단원 뒤 순차 개방, **1~12단원 정규 퍼즐 전부 완료 시 전체 과정 완주** 연출(월드 기호가 모이고 개념을 짧게 되짚음, 동작 줄이기면 정지 그림). 보너스·예측은 조건에서 제외.
