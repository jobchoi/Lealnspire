## T71 구현 기록 (Codex, 2026-11-27) [제안·잠정]

u12-1~3의 맵·입력·팔레트·상한은 위 설계 그대로다. 정답은 6/6맵 성공이며 while 인정 풀이와 for each 인정 풀이도 각각 두 맵 성공한다(u12-2는 설계에 별도 인정 풀이가 없어 같은 매개변수 정답을 재검사). 블록 수는 함수 몸체 포함 4/6/4다. 11단원 이후 순차 개방·이어하기와 마지막의 목록 복귀를 연결했다. 단원 묶음·맵 그룹 접근성 이름·결과 문구는 params/lists 여부보다 u12 접두사를 우선한다. 저장 v2의 기존 params/lists 허용 정책으로 repeat A와 ◆/리스트 원천을 왕복 복원하며 u5/u6 전용 허용은 확장하지 않았다. 손상 코드만 비우고 해당 완료·별 및 다른 스테이지 코드는 보존한다.

u12-2는 기존 7단원과 같은 최소 비용 전체 상태 변환 합성이다. 한 번만 등장하는 호출은 인라인하여 비용을 낮출 수 있으므로 추가 한 함수 몸체는 2~4노드, 두 함수 몸체 합계는 0~4노드를 열거한다. 실제 실행 상한을 완화한 상위 집합에서도 해가 없다. 합성 작업 상한 100만·정확한 후보 수를 단언한다. u12-3은 실제 실행기로 모든 트리를 검사하며 ID를 재부여하고 작업 상한 100만·정확한 후보 수를 단언한다. 전제인 시작 E·A·팔레트·배타적인 플래그도 고정한다. 이 증명은 특정 블록 하나만 유일한 정답이라는 주장이 아니다.

전체 완주는 1~12단원 정규 45퍼즐을 모두 완료해야 한다. 보너스 2개·예측은 제외하며 별 수는 요구하지 않는다. 목록과 성공 결과 창에 SVG 월드 기호가 모이는 연출·짧은 개념 되짚기·전체 완주 문구를 표시한다. 동작 줄이기에서는 정지 그림이며 저장에 새 완료 플래그를 추가하지 않는다. 정규 퍼즐 하나라도 미완료인 경우 전체 완주를 표시하지 않는 것을 전수 검사한다. 변경 전 실행기로 캡처한 fixture는 1~11단원 전체 44스테이지(보너스 포함)·75맵의 결과와 모든 프레임을 비교한다. 기존의 오래된 fixture 검사는 12단원을 범위에서 제외하며 기존 검증 내용은 유지한다.
