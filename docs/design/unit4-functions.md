# T45 — 4단원 함수 [제안·잠정]

모든 맵은 시작 방향 E. F=앞으로, L=왼쪽, R=오른쪽, A=별 함수 호출입니다. 함수 정의 자체는 블록 수에 포함하지 않습니다.

| 스테이지 | 월드 | 별 함수 몸체 | main 정답 | 총 블록/상한 | 크기 |
|---|---|---|---|---|---|
| u4-1 | sketchbook | F L F | A F R A A | 8/8 | 3×5 |
| u4-2 | train | F repeat 2 [F L F] R | A F A A | 10/10 | 6×6 |
| u4-3 | handheld | repeat 2 [F R F] L | A F A A | 9/9 | 5×5 |

u4-1: 같은 모양을 세 번 부르며, 사이의 F R과 빈 간격 때문에 단순 반복으로 대체할 수 없습니다.

```text
#G.
##.
#..
#.#
S.#
```

u4-2: 함수 안 반복을 통해 몸체를 6블록으로 만듭니다.

```text
##...#
...#.#
.###.#
.G##..
#####.
###S..
```

u4-3: 위의 정답 몸체가 정의되어 있지만 초기 main은 비어 있습니다. 실행하면 움직이지 않고 unfinished가 됩니다. main에 호출과 연결 동작을 추가해 고칩니다.

```text
###S.
.G##.
.##..
..#.#
#...#
```

## 증명과 테스트

`src/model/stages/stages.test.ts`의 T39/T42 상태 변환 합성 전수 탐색을 4단원에도 적용합니다. 각 통행 칸·방향을 시작 상태로 두고 성공·충돌을 흡수 상태로 취급합니다. primitive + tail, repeat(body, count 2~10) + tail을 블록 수별로 합성하고 같은 변환은 최소 비용 하나로 합칩니다. 중첩 반복과 모든 횟수를 포함하며, 빈 반복은 항등 변환이므로 제외해도 반례를 놓치지 않습니다. 실행 상한을 제거한 더 넓은 실행 집합에서도 정답이 없으므로 실제 실행기에서도 함수 없는 우회가 없습니다.

각 maxBlocks 이하에서 함수 없는 정답 **0개**. 후보 설계 시 독립 탐색의 서로 다른 변환 수(항등 포함)는 u4-1 620개, u4-2 3,872개, u4-3 2,456개였습니다. 저장소 테스트는 같은 합성 방법으로 불가능성을 검증합니다. 함수 정답은 엔진에서 성공하고 합산 상한 이내이며 모든 통행 칸을 방문합니다.

추가 회귀: 함수 몸체 중첩 반복·횟수 변경·이동·삭제, 별/달 호출 구별, 함수 안 호출 차단, 함수 삭제와 호출 동시 삭제·되돌리기, u3-3 이후 잠금 해제·이어하기·3별 저장·목록 복귀, 정의만 있을 때 미실행, ko/en×세 월드의 호출 위치별 타일·카드·몸체 강조. 기존 1~3단원 프레임 fixture 검증은 해당 단원 전체를 유지합니다.
