# 8단원 반환값 — 함수가 값을 돌려줌 [제안·잠정]

> 기획: GPT 독립 기획안(2026-11-26, 읽기 전용, 원문 `~/project/_progress/logs/unit8-gpt-plan.md`) → Claude 검토·확정(세 퍼즐 경로 직접 추적). 근거: ROADMAP 라운드 3 반환값 행("화면에 보여 주면 반환한 것", "return 뒤에도 실행한다" 오해).

## 1. 배울 것

- 함수가 계산한 값을 `return`으로 **돌려주고**, 부른 쪽(repeat 횟수)이 그 값을 쓴다.
- `return`은 함수를 **바로 끝낸다**(뒤의 블록은 이번 호출에서 실행 안 됨).
- 센서가 보여 주는 숫자(관찰)와 돌려받은 값(전달)은 다르다 — 돌려받으려면 return이 실행돼야 한다.

## 2. 의미 (Model)

- **숫자 센서** `앞 칸 수`: 바라보는 방향으로 벽(또는 맵 끝) 전까지 열린 칸 수(목표 칸 포함, 0~20). 로봇은 움직이지 않음. 이번 단원은 앞 방향만, return의 값 슬롯에서만 사용.
- `return` 블록: 값 = 숫자 0~20 · A · ◆ · 앞 칸 수. 함수 몸체에서만(main 거부). 실행하면 현재 함수 전체 종료(반복 안에서도), 값을 호출자에게.
- repeat 횟수 원천에 **값 호출** `repeat [★(인자?)]` 추가: 진입 시 함수를 한 번 호출, 돌려받은 값으로 횟수 고정. return 없이 끝나면 새 결과 `missingReturn`(0으로 보정하지 않음, 원인 블록 = 그 repeat). 문장 호출(기존 `★()`)은 반환값을 버림.
- 실행기 중단 신호를 계속/반환(값)/중단(결과)로 분리. 호출·return·센서도 단계 예산에 포함, 기존 1000단계·반복 진입 제한 유지. 함수 몸체 호출 금지 유지.
- 프레임: 호출 순번·입력값·return 블록·반환값·그 값을 쓴 repeat ID. 블록 수: return·값 호출 repeat 각 1, 값 슬롯·정의 0.
- 저장: v2 유지(6·7단원과 같은 방침), 새 필드 검증, 8단원 스테이지는 `returns: true`, 허용 안 된 스테이지는 그 코드만 비움.

## 4. 화면

- 함수 카드에 입력 홈 ◆(왼쪽)과 출력 홈 ↩(오른쪽)을 다른 모양으로. return 타일 `↩ 앞 칸 수`.
- 실행 중: `◆1 → ★ → ↩4 → repeat ×4`처럼 전달을 표시, return 뒤 블록은 "이번 호출에서 실행 안 함"으로 흐리게(색만으로 구분 금지). 센서 관찰 숫자(맵 위)와 돌려받은 값(repeat 옆)은 모양·위치·라벨로 구분.
- missingReturn 실패 문구: ko "함수가 값을 돌려주지 않았어요. return이 실행됐나요?", en "The function didn't return a value. Did return run?"
